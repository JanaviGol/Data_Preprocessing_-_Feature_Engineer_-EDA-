Core Idea — Ek Line Mein
Categorical Encoding = text categories ko numbers mein convert karna — taaki ML models samajh sakein.

ML models sirf numbers samjhte hain. "Mumbai", "Delhi", "Chennai" — ye ML model ke liye meaningless hai. Inhe numbers mein badalna padega!
Problem — ML Model ke Saath
df['city'] = ['Mumbai', 'Delhi', 'Chennai']
model.fit(X, y) → ValueError! could not convert string to float: 'Mumbai'

ML algorithms (LinearRegression, RandomForest, SVM) — ye sab sirf numerical input accept karte hain. Strings = crash!
Teen Main Encoding Types
🔢
Ordinal Encoding
Ordered categories ko numbers dete hain. Order matter karta hai!
Low=1, Medium=2, High=3
🏷️
Label Encoding
Har unique category ko ek number dete hain — alphabetical order mein. Target variable ke liye best!
🔥
One Hot Encoding
Har category ke liye alag column banate hain — 0 ya 1. No fake ordering! Nominal data ke liye best.

🎓 UPSC: "Education" → 10th=1, 12th=2, Grad=3 (Ordinal)
🛒 Swiggy: "Cuisine" → Indian, Chinese, Italian (OHE)

Level 1 · Skill Unlock
Ordinal Encoding — Ordered Categories ko Numbers Dena
Ordinal Encoding kya hai?
Ordinal = ek meaningful order wali categories ko numbers assign karna — order preserve hota hai.

Jaise education level: 10th < 12th < Graduate < Post-Graduate — ye ek clear ranking hai. Yahan order matter karta hai, isliye ordinal encoding best hai!
Golden Rule — Kab Use Karein
Ordinal Encoding tab use karo jab categories ka natural order/ranking ho:
✅ Education: School < Graduate < Post-Graduate
✅ Satisfaction: Low < Medium < High
✅ T-Shirt Size: S < M < L < XL
❌ City: Mumbai, Delhi, Chennai — yahan koi order nahi hai!
Ordinal Encoding — 3 Tarike (Manual, Map, sklearn)
🐍 Python — Ordinal Encoding
import pandas as pd
import numpy as np
from sklearn.preprocessing import OrdinalEncoder

# ─── Dataset: HDFC Loan Applications ───
data = {
    'applicant': ['Aarav', 'Priya', 'Ravi', 'Sneha', 'Karan',
                  'Divya', 'Mohit', 'Ananya'],
    'education': ['Graduate',      'Post-Graduate', 'School',
                  'Graduate',      'Post-Graduate', 'School',
                  'Graduate',      'Post-Graduate'],
    'income_level': ['Low',    'High',   'Medium', 'High',
                     'Low',    'Medium', 'High',   'Low'],
    'loan_approved': [1, 1, 0, 1, 0, 1, 1, 0],
}
df = pd.DataFrame(data)

print("Original Data:")
print(df[['applicant', 'education', 'income_level']])

# ════════════════════════════════════════
# METHOD 1: Manual Map — Sabse Simple, Full Control
# ════════════════════════════════════════
education_order = {'School': 1, 'Graduate': 2, 'Post-Graduate': 3}
income_order    = {'Low': 1, 'Medium': 2, 'High': 3}

df['education_enc']    = df['education'].map(education_order)
df['income_level_enc'] = df['income_level'].map(income_order)

print("\n--- Method 1: Manual Map ---")
print(df[['education', 'education_enc', 'income_level', 'income_level_enc']])

# ════════════════════════════════════════
# METHOD 2: sklearn OrdinalEncoder
# (Machine Learning pipelines ke liye best)
# ════════════════════════════════════════
enc = OrdinalEncoder(
    categories=[
        ['School', 'Graduate', 'Post-Graduate'],   # education order
        ['Low', 'Medium', 'High'],                  # income order
    ]
)

df_encoded = df[['education', 'income_level']].copy()
df[['edu_sklearn', 'income_sklearn']] = enc.fit_transform(df_encoded)

print("\n--- Method 2: sklearn OrdinalEncoder ---")
print(df[['education', 'edu_sklearn', 'income_level', 'income_sklearn']])
# Note: sklearn 0-indexed (School=0, Graduate=1, Post-Graduate=2)
# Manual map 1-indexed (School=1, Graduate=2, Post-Graduate=3)
🔢 Ordinal Encoding Done! education: School=1, Graduate=2, Post-Graduate=3. income_level: Low=1, Medium=2, High=3. Ab ML model samjhega ki Post-Graduate > Graduate > School — order preserved! sklearn version 0-based hota hai (School=0, Graduate=1, Post-Graduate=2).

Level 2 · Boss Topic
Label Encoding — Har Category Ko Ek Number
+30 XP on scroll
Label Encoding kya hai?
Label Encoding = har unique category ko ek unique integer assign karna — alphabetical order mein (0 se shuru).

Simple aur fast! "Cat"=0, "Dog"=1, "Fish"=2 — bas itna. Koi order assume nahi hota theoretically, lekin ML models number ki magnitude se influence ho sakte hain.
Label Encoding kab use karein
✅ Target variable (y) encode karne ke liye — hamesha LabelEncoder
✅ Tree-based models (RandomForest, XGBoost, Decision Tree)
✅ Binary categories: Yes/No, Male/Female, True/False
✅ Jab categories ki sankhya bahut zyada ho (OHE se bahut columns ban jaate)
Label Encoding kab avoid karein
❌ Linear Regression, SVM, KNN — ye magnitude assume karte hain
❌ Nominal features (City, Color) — fake ordering create hoti hai
❌ Multiclass nominal features with linear models → OHE better hai
❌ Jab categories mein koi natural rank na ho
Label Encoding — sklearn LabelEncoder + pandas map
🐍 Python — Label Encoding
import pandas as pd
from sklearn.preprocessing import LabelEncoder

# ─── Dataset: Ola Driver Classification ───
data = {
    'driver_id': [1, 2, 3, 4, 5, 6, 7, 8],
    'city':      ['Mumbai', 'Delhi', 'Pune', 'Mumbai',
                  'Chennai', 'Delhi', 'Pune', 'Chennai'],
    'vehicle':   ['Auto', 'Bike', 'Car', 'Car',
                  'Auto', 'Car', 'Bike', 'Auto'],
    'gender':    ['Male', 'Female', 'Male', 'Female',
                  'Male', 'Male', 'Female', 'Female'],
    'churned':   ['Yes', 'No', 'No', 'Yes',
                  'No', 'Yes', 'No', 'No'],   # Target variable!
}
df = pd.DataFrame(data)

print("Original Data:")
print(df)

# ════════════════════════════════════════
# METHOD 1: sklearn LabelEncoder — TARGET ke liye best
# ════════════════════════════════════════
le = LabelEncoder()

# Target variable encode karo
df['churned_enc'] = le.fit_transform(df['churned'])
print("\n--- Target Variable (churned) Encoded ---")
print(f"Classes: {le.classes_}")   # ['No', 'Yes']
print(f"Mapping: No→{le.transform(['No'])[0]}, Yes→{le.transform(['Yes'])[0]}")
print(df[['churned', 'churned_enc']])

# ════════════════════════════════════════
# METHOD 2: Alag alag columns encode karo
# ════════════════════════════════════════
le_city    = LabelEncoder()
le_vehicle = LabelEncoder()
le_gender  = LabelEncoder()

df['city_enc']    = le_city.fit_transform(df['city'])
df['vehicle_enc'] = le_vehicle.fit_transform(df['vehicle'])
df['gender_enc']  = le_gender.fit_transform(df['gender'])

print("\n--- Feature Columns Encoded ---")
print(df[['city', 'city_enc', 'vehicle', 'vehicle_enc', 'gender', 'gender_enc']])

# Mappings dekho
print("\nCity Mapping:")
for label, num in zip(le_city.classes_, range(len(le_city.classes_))):
    print(f"  {label} → {num}")

# ════════════════════════════════════════
# Inverse transform — numbers wapas strings mein
# ════════════════════════════════════════
print("\nInverse Transform example:")
print(le.inverse_transform([0, 1, 0]))  # [0,1,0] → ['No','Yes','No']
🏷️ Label Encoding Done! churned: No=0, Yes=1 (target perfect!). city: Chennai=0, Delhi=1, Mumbai=2, Pune=3 (alphabetical). vehicle: Auto=0, Bike=1, Car=2. gender: Female=0, Male=1. Tree-based models ke liye ready!
🤔 Label Encoding mein categories alphabetical order mein 0 se number milte hain. Ek "city" column mein ["Pune", "Mumbai", "Delhi", "Chennai"] hai. Delhi ko kaunsa number milega?
A0 — kyunki list mein 3rd position pe hai
B2 — list mein position 3 hai toh 2 (0-indexed)
C1 — alphabetically Chennai=0, Delhi=1, Mumbai=2, Pune=3
D3 — kyunki 4 cities hain aur Delhi last mein hai

One Hot Encoding — Har Category Alag Column Mein!
+30 XP on scroll
One Hot Encoding kya hai?
One Hot Encoding (OHE) = har unique category ke liye ek nayi binary column banao — value ya toh 0 ya 1.

"Mumbai", "Delhi", "Chennai" → teen columns: is_Mumbai, is_Delhi, is_Chennai
Koi fake ordering nahi! Har city equal aur independent hai — bilkul sahi!
OHE Visually — Kya Hota Hai?
Before OHE
NameCity
AaravMumbai
PriyaDelhi
RaviChennai
SnehaMumbai
1 column — strings
➡️
get_dummies()
After OHE
Namecity_Chennaicity_Delhicity_Mumbai
Aarav001
Priya010
Ravi100
Sneha001
3 binary columns — no ordering!
Dummy Variable Trap — Hamesha Yaad Rakho!
3 cities ke liye sirf 2 columns kaafi hain! Agar Chennai=0, Delhi=0 → automatically Mumbai hai — 3rd column redundant hai.

Agar teeno columns rakho toh multicollinearity hoti hai — linear models confuse ho jaate hain.
Fix: drop_first=True (pandas) ya drop='first' (sklearn) — ek column hata do!

Exception: Tree-based models (RandomForest, XGBoost) ko dummy trap ki chinta nahi — unhe sab columns rakhne do.
🤔 One Hot Encoding mein "Dummy Variable Trap" se bachne ke liye kya karna chahiye aur kyun?
AHar category ke liye ek extra column add karo
BOHE ki jagah Label Encoding use karo
CEk column ko NaN se replace karo
Ddrop_first=True lagao — ek column automatically drop ho jaata hai, multicollinearity hatati hai

One Hot Encoding — pandas get_dummies vs sklearn
One Hot Encoding — Dono Tarike Seekho
🐍 Python — One Hot Encoding
import pandas as pd
import numpy as np
from sklearn.preprocessing import OneHotEncoder

# ─── Dataset: Swiggy Restaurant Orders ───
data = {
    'order_id':  [1001, 1002, 1003, 1004, 1005, 1006, 1007, 1008],
    'city':      ['Mumbai',    'Delhi',    'Pune',     'Mumbai',
                  'Chennai',   'Delhi',    'Pune',     'Chennai'],
    'cuisine':   ['Indian',    'Chinese',  'Italian',  'Indian',
                  'Chinese',   'Italian',  'Indian',   'Chinese'],
    'payment':   ['UPI',       'Card',     'Cash',     'UPI',
                  'Card',      'UPI',      'Cash',     'Card'],
    'amount':    [350, 520, 180, 430, 290, 610, 240, 380],
}
df = pd.DataFrame(data)

print("Original Data:")
print(df)
print(f"\nOriginal shape: {df.shape}")

# ════════════════════════════════════════
# METHOD 1: pandas get_dummies — Quick & Easy
# ════════════════════════════════════════
# Ek column ke liye
df_city_ohe = pd.get_dummies(df['city'], prefix='city')
print("\n--- City OHE (get_dummies) ---")
print(df_city_ohe)

# Sabhi categorical columns ek saath
df_ohe = pd.get_dummies(
    df,
    columns=['city', 'cuisine', 'payment'],
    prefix=['city', 'cuisine', 'pay'],
    drop_first=True     # Dummy variable trap se bacho!
)

print("\n--- Full OHE (all categorical columns) ---")
print(df_ohe.head())
print(f"New shape: {df_ohe.shape}")  # zyada columns!
print(f"New columns: {list(df_ohe.columns)}")

# ════════════════════════════════════════
# METHOD 2: sklearn OneHotEncoder
# (Pipeline mein use ke liye best)
# ════════════════════════════════════════
ohe = OneHotEncoder(
    drop='first',           # Dummy trap se bacho
    sparse_output=False,    # Dense array chahiye
    handle_unknown='ignore' # Test mein naya value aaye toh ignore
)

# Sirf categorical columns
cat_cols = ['city', 'cuisine', 'payment']
encoded_arr = ohe.fit_transform(df[cat_cols])

# Feature names nikalte hain
feature_names = ohe.get_feature_names_out(cat_cols)

df_sklearn_ohe = pd.DataFrame(encoded_arr, columns=feature_names)

print("\n--- sklearn OneHotEncoder ---")
print(df_sklearn_ohe.head())
print(f"\nGenerated feature names: {feature_names.tolist()}")
🔥 OHE Done! city (3 cities) → 2 columns with drop_first (city_Delhi, city_Pune). cuisine (3) → 2 columns. payment (3) → 2 columns. Total: 6 new binary columns replace karte hain 3 original columns. handle_unknown='ignore' — test mein nayi city aaye toh crash nahi hoga!

Kaunsa Encoding Kab? — Expert Decision Guide
+30 XP on scroll
Sahi Encoding Choose Karna = Expert Skill
Galat encoding se model ka performance significantly drop ho sakta hai! Ye decision tree tumhare liye expert choice easy banata hai — bas 3 sawaal puchho!
📊 Kya ye Target Variable (y) hai?
Agar haan → LabelEncoder use karo. Target variable mein order nahi chahiye — bas unique numbers.
Example: churned: Yes=1, No=0 | spam: spam=1, ham=0
🔢 Kya categories mein natural order/ranking hai?
Agar haan → OrdinalEncoder ya manual map() use karo.
Examples: Low/Medium/High · School/Graduate/PG · Poor/Good/Excellent · S/M/L/XL
🏙️ Koi order nahi, nominal categories hain?
→ One Hot Encoding use karo — especially Linear models ke saath
→ LabelEncoder acceptable hai tree-based models ke saath (RandomForest, XGBoost)
Examples: City, Color, Cuisine, Blood Group, Product Category
⚠️ Bohot zyada categories hain (100+)?
OHE se bahut columns ban jaate hain → Target Encoding ya Frequency Encoding better option hai (advanced topic).
Example: Pincode column — 1000+ unique values → OHE se 1000 columns!
