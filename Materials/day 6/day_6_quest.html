MICE ka Full Form
Multivariate Imputation by Chained Equations

Ye naam sun ke darr mat jao! Iska matlab bahut simple hai — missing values ko fill karo, doosri columns ki help lekar. Ek column ki value predict karo baaki columns se.
Pehle — Simpler Imputation kyun nahi kaafi?
Humne pehle seekha: missing values ko mean ya median se fill karo. Ye kaam karta hai, lekin ek problem hai...

Mean imputation ek global average deta hai — chahe row ka context kuch bhi ho!

Socho: Ek 5-star restaurant ka average bill ₹1500 hai aur ek 2-star dhaba ka ₹120. Agar dono ka bill missing ho toh mean imputation dono ko ₹450 de dega — galat!

MICE samjhta hai: context matter karta hai — aur doosri columns se context milta hai!
Ek Line Mein MICE ka Idea
🎯
Column A missing hai?
Column B, C, D ko dekho. Unka use karo Column A ki value predict karne ke liye — jaise ek detective clues se jawab dhundta hai!
🔗
Chained = Ek ke baad ek
Pehle A predict karo B, C se. Phir B predict karo A, C se. Phir C predict karo A, B se. Ye chain chalti rehti hai — isliye "Chained"!
🔄
Multiple Rounds = Better Guesses
Pehla round = rough guess. Doosra round = better. Teesra = aur better. Har round mein values improve hoti hain — convergence tak!
🤔 MICE aur simple mean imputation mein sabse bada farak kya hai?
AMICE zyada fast aur simple hai
BMICE doosri columns ka context use karta hai; mean imputation sirf overall average deta hai
CMICE sirf numerical columns mein kaam karta hai, mean imputation NaN bhi handle karta hai
DMICE outliers ko automatically remove karta hai

Detective Analogy — MICE ko Samjho
Socho tum ek detective ho. Tumhare paas ek missing information hai — ek suspect ka age. Tumhare paas clues hain: uski job title, salary, aur years of experience.

Tum in clues se age estimate karoge — ek overall average se nahi, balki is specific person ke context se.

MICE ke 3 Simple Steps
🌱 Step 1 — Initial Fill (Rough Placeholder)
Sabse pehle, sab NaN ko ek simple value se fill karo — jaise mean ya median. Ye final values nahi hain — sirf ek starting point taaki aage prediction ho sake.

Jaise ek exam mein sab questions ka answer pahle "B" likh do — phir wapas jaake sahi karo!
Avg_Bill NaN → ₹282.5 (mean placeholder)
🎯 Step 2 — Column by Column Predict Karo
Ab ek column ko target banao jisme NaN tha. Baaki saari columns ko features ki tarah use karo. Ek simple prediction model chalao.

→ Avg_Bill predict karo using Rating + Delivery_Time (as features)
→ Ye model dekhta hai: jahan Rating high hai aur Delivery_Time kam hai, wahan Bill zyada hoti hai
→ Ab NaN wali rows ke liye predict karo → PizzaPalace → ₹410, BurgerZone → ₹240

Phir same cheez doosri column ke liye karo (Rating, phir Delivery_Time).
🔄 Step 3 — Dobara Karo (Iterate)
Ab ek round complete hua. Imputed values pahle se better hain. Lekin perfect nahi hain.

Step 2 dobara karo — is baar better imputed values features ke taur pe milti hain → aur better predictions aati hain!

Ye cycle kai baar chalti hai (default: 10 rounds). Har round mein values thodi aur accurate hoti hain.
Jab values zyada change nahi karti → converge ho gayi → bas karo!

🐍 Code Block 1 — Manual MICE Logic (pandas only) 
import pandas as pd
import numpy as np

# ─── Hamaara Zomato dataset ───
data = {
    'Avg_Bill':       [350,   np.nan, 180,   np.nan, 120,   480  ],
    'Rating':         [4.2,   4.5,    np.nan, 3.8,   4.0,   np.nan],
    'Delivery_Time':  [30,    25,     40,     np.nan, 20,   35   ],
}
df = pd.DataFrame(data)

print("Original Data:")
print(df)
print("\nMissing values per column:")
print(df.isnull().sum())

# ════════════════════════════════════════════════
# STEP 1: Initial Fill — sab NaN ko mean se bharo
#         Ye sirf placeholder hai, final nahi!
# ════════════════════════════════════════════════
df_work = df.copy()
for col in df_work.columns:
    col_mean = df_work[col].mean()   # non-null values ka mean
    df_work[col] = df_work[col].fillna(col_mean)

print("\n--- After Initial Fill (Step 1) ---")
print(df_work.round(2))
# Ab koi NaN nahi — sab columns mein values hain!
# Ye rough guess hai — asli MICE iteration abhi shuru hoga

# ════════════════════════════════════════════════
# STEP 2: Iterations — 3 rounds chalao
#         Har round mein har column ek baar predict hogi
# ════════════════════════════════════════════════

# Yaad rakhein konse rows mein original NaN tha
original_nan_mask = df.isnull()

num_iterations = 3   # sirf 3 rounds for demonstration

for iteration in range(1, num_iterations + 1):
    print(f"\n{'='*40}")
    print(f"  ITERATION {iteration}")
    print(f"{'='*40}")

    for target_col in df.columns:
        # Kya is column mein originally NaN tha?
        nan_rows = original_nan_mask[target_col]
        if nan_rows.sum() == 0:
            print(f"  {target_col}: koi NaN nahi — skip")
            continue

        # Features = baaki saari columns
        feature_cols = [c for c in df.columns if c != target_col]

        # Training data = jinke paas ORIGINAL value thi (non-null rows)
        train_mask = ~nan_rows
        X_train = df_work.loc[train_mask, feature_cols]
        y_train = df.loc[train_mask, target_col]

        # Bahut simple prediction: weighted average using correlation
        # (sklearn ke andar BayesianRidge ya LinearRegression hoti hai)
        # Hum simple formula use kar rahe hain samjhane ke liye:
        # prediction = mean + (feature se adjustment)
        col_mean = y_train.mean()

        # Predict for missing rows using feature average adjustment
        for row_idx in df_work.index[nan_rows]:
            feature_vals = df_work.loc[row_idx, feature_cols]
            feature_means = df_work.loc[train_mask, feature_cols].mean()

            # Simple: agar features mean se upar hain toh target bhi thoda upar
            deviation = ((feature_vals - feature_means) / (feature_means + 1e-9)).mean()
            prediction = col_mean * (1 + deviation * 0.3)  # 0.3 = dampening factor
            df_work.loc[row_idx, target_col] = prediction

        print(f"  {target_col} → NaN rows {list(df_work.index[nan_rows])} updated")

    print(f"\n  Snapshot after Iteration {iteration}:")
    print(df_work.round(2))

print("\n" + "="*40)
print("FINAL IMPUTED VALUES:")
print("="*40)
print(df_work.round(2))

# Compare: kahan kahan NaN tha, ab kya mila?
print("\nKahan NaN tha → Ab kya imputed mila:")
for col in df.columns:
    nan_rows = original_nan_mask[col]
    if nan_rows.sum() > 0:
        print(f"\n  {col}:")
        for idx in df_work.index[nan_rows]:
            print(f"    Row {idx}: NaN → {df_work.loc[idx, col]:.2f}")
💡 Ye manual code exactly wahi logic follow karta hai jo MICE internally karta hai: → Step 1: Mean se fill (placeholder) → Step 2: Har column ko target banao, baaki se predict karo → Iterate: Values har round mein improve hoti hain Actual sklearn IterativeImputer mein BayesianRidge model use hota hai (hum ne simple formula use kiya) — lekin flow bilkul same hai!

"Chained Equations" ka matlab kya hai?
Socho teen dost hain — Aman, Bela, aur Chetan. Unhe ek doosre ka birthday guess karna hai par unhe nahi pata.

→ Aman guess karta hai Bela aur Chetan ki hints se
→ Bela guess karti hai Aman aur Chetan ki hints se
→ Chetan guess karta hai Aman aur Bela ki hints se

Shuruaat mein sab galat hain. Phir woh ek doosre ki guesses se update karte hain. Round 2, Round 3 — har baar better guesses! Yahi chained equations hai!
Common Sawaal — Beginners Ke

Kitne iterations best hai?
max_iter = 10 (default)
Default 10 rounds zyada tar datasets ke liye kaafi hai. Na zyada sochna! 10 se shuru karo — bus itna.
✅ Beginner ke liye: max_iter=10 always
❓
Convergence kya hota hai?
Values stable ho jaati hain
Jab ek iteration se agla iteration mein values bahut kam change ho rahi hon — matlab imputation stable ho gayi. MICE apne aap ruk jaata hai!
Iteration 7: Bill=₹382 | Iteration 8: Bill=₹382.1 → Stable!

Andar kaunsa model predict karta hai?

sklearn mein by default BayesianRidge use hota hai — ye ek linear regression ka better version hai. Beginners ke liye: default rahne do, koi change mat karo!
Beginner ke liye: default estimator use karo — bas!

random_state kyun set karein?

MICE mein kuch randomness hoti hai initial fill mein. random_state=42 set karne se har baar same results aate hain — reproducibility ke liye!
✅ Hamesha random_state=42 lagao — adat daalo!

🐍 Code Block 2 — sklearn IterativeImputer (Final Clean Code) 
import pandas as pd
import numpy as np

# Step 1: Ye line likhna ZAROORI hai — mat bhuolo!
from sklearn.experimental import enable_iterative_imputer
from sklearn.impute import IterativeImputer

# ─── Hamaara same Zomato dataset ───
data = {
    'Avg_Bill':       [350,   np.nan, 180,   np.nan, 120,   480  ],
    'Rating':         [4.2,   4.5,    np.nan, 3.8,   4.0,   np.nan],
    'Delivery_Time':  [30,    25,     40,     np.nan, 20,   35   ],
}
df = pd.DataFrame(data)

print("Original Data (NaN = missing):")
print(df)
print(f"\nTotal missing values: {df.isnull().sum().sum()}")

# ─── IterativeImputer — MICE ───
# Sirf 2 parameters beginners ke liye zaruri hain:
#   max_iter  = kitne rounds chalega (10 enough hai)
#   random_state = reproducibility ke liye (hamesha 42 likho)
imputer = IterativeImputer(max_iter=10, random_state=42)

# fit_transform = dataset pe MICE apply karo
# Ye ek numpy array return karta hai → DataFrame mein convert karo
df_imputed = pd.DataFrame(
    imputer.fit_transform(df),
    columns=df.columns
)

print("\nAfter MICE Imputation (sabhi values fill ho gayi!):")
print(df_imputed.round(2))

print(f"\nTotal missing values after: {df_imputed.isnull().sum().sum()}")
# → 0! Koi NaN nahi baka!

# ─── Compare karo: Mean vs MICE ───
print("\n--- Comparison: Mean vs MICE ---")
mean_fill = df.fillna(df.mean())

print("\nPizzaPalace Avg_Bill:")
print(f"  Mean fill  → ₹{mean_fill.loc[1, 'Avg_Bill']:.0f}  (overall average)")
print(f"  MICE fill  → ₹{df_imputed.loc[1, 'Avg_Bill']:.0f}  (context-aware!)")

print("\nBurgerZone Avg_Bill:")
print(f"  Mean fill  → ₹{mean_fill.loc[3, 'Avg_Bill']:.0f}  (same as PizzaPalace — wrong!)")
print(f"  MICE fill  → ₹{df_imputed.loc[3, 'Avg_Bill']:.0f}  (lower — BurgerZone ka rating kam hai)")
