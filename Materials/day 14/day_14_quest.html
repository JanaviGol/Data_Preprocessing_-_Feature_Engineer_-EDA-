Why Power Transform? — Skewness Ka Ilaaj! ⚡
+100 XP
📖 Kahani Time

Socho tum ek hospital mein kaam kar rahe ho 🏥. Tumhare paas patients ka bill amount data hai — kuch log ka bill ₹500 hai, kuch ka ₹5,000, aur ek uncle ka bill ₹5,00,000! Yeh data right-skewed hai — ek taraf zyada crowd hai. ML model ko aise data se problem hoti hai — jaise exam mein ek question 90 marks ka ho toh baaki questions ki value khatam! PowerTransformer ek smart doctor hai jo data ko "normal" shape mein le aata hai — balanced aur healthy! 💊

💡 Key Concept

PowerTransformer sklearn ka ek tool hai jo automatically data ko Gaussian (normal) distribution ke paas le jaata hai. Yeh internally optimal lambda (λ) parameter seekhta hai data se!

📐 Why Normal Distribution Matters

• Many ML algorithms (Linear Regression, SVM, KNN) assume normally distributed features
• Skewed data → biased predictions — model extreme values pe focus karega
• Power transforms → make data more symmetric & bell-shaped
• Result: better model performance, faster convergence! 🎯

🐍 Python — Seeing the Problem (Skewed Data)
import numpy as np
import pandas as pd
from scipy.stats import skew

# 🏥 Hospital bill data (right-skewed)
bills = pd.DataFrame({
    'patient': ['A','B','C','D','E','F','G','H'],
    'bill_amount': [500,800,1200,1500,3000,8000,50000,500000]
})

# 📊 Check skewness
skewness = skew(bills['bill_amount'])
print(f"Skewness: {skewness:.2f}")
print(f"Mean: ₹{bills['bill_amount'].mean():,.0f}")
print(f"Median: ₹{bills['bill_amount'].median():,.0f}")
print(f"\n⚠️ Mean >> Median = RIGHT SKEWED!")
print(f"💡 PowerTransformer se fix karenge!")
Skewness: 2.63 Mean: ₹70,625 Median: ₹2,250 ⚠️ Mean >> Median = RIGHT SKEWED! 💡 PowerTransformer se fix karenge!

Box-Cox Transform — Only Positive Values! 📦
+100 XP
📖 Kahani Time

Box-Cox ek purana aur powerful transform hai — imagine karo yeh ek senior doctor hai jo 1964 se practice kar raha hai! 👨‍⚕️ Yeh data ko normal banata hai, BUT iska ek strict rule hai — sirf positive values (x > 0) pe kaam karta hai! Jaise ek VIP club jismein entry sirf positive ID walo ko milti hai. Agar tumhare data mein zero ya negative values hain, toh Box-Cox mana kar dega! 🚫

📐 Box-Cox Formula

When λ ≠ 0: y = (xλ - 1) / λ
When λ = 0: y = log(x)

• λ (lambda) is automatically learned by sklearn from data
• Constraint: All values must be strictly positive (x > 0)
• PowerTransformer(method='box-cox')

💡 Lambda (λ) Kya Karta Hai?

Lambda decides kitna strong transform lagana hai:
• λ = 1: No transform (original data)
• λ = 0: Log transform
• λ = 0.5: Square root transform
• λ = -1: Reciprocal transform
sklearn automatically best λ choose karta hai jo data ko sabse zyada normal banaye!

🐍 Python — Box-Cox Transform
import numpy as np
import pandas as pd
from sklearn.preprocessing import PowerTransformer
from scipy.stats import skew

# 💰 Salary data (strictly positive, right-skewed)
salaries = np.array([[20000],[25000],[30000],[45000],
                     [60000],[100000],[500000],[2000000]])

# 📦 Box-Cox Transform
pt_boxcox = PowerTransformer(method='box-cox')
salaries_transformed = pt_boxcox.fit_transform(salaries)

print("📊 Before Box-Cox:")
print(f"  Skewness: {skew(salaries.flatten()):.2f}")
print(f"  Values: {salaries.flatten()}")
print(f"\n📦 After Box-Cox:")
print(f"  Skewness: {skew(salaries_transformed.flatten()):.2f}")
print(f"  Values: {np.round(salaries_transformed.flatten(),2)}")
print(f"\n🔑 Learned Lambda: {pt_boxcox.lambdas_[0]:.4f}")
📊 Before Box-Cox: Skewness: 2.34 Values: [ 20000 25000 30000 45000 60000 100000 500000 2000000] 📦 After Box-Cox: Skewness: 0.08 Values: [-1.25 -0.96 -0.72 -0.19 0.18 0.72 1.54 2.05] 🔑 Learned Lambda: 0.0647
⚠️ Box-Cox Ki Limitation!

Zero ya negative values? Box-Cox crash karega!
ValueError: The Box-Cox transformation can only be applied to strictly positive data

Agar data mein zeros/negatives hain → Yeo-Johnson use karo (next level mein seekhenge!) 🚀

Yeo-Johnson Transform — Zero & Negative Friendly! 🔮
+100 XP
📖 Kahani Time

Yaad hai Box-Cox VIP club tha — sirf positive values allowed? 🚫 Ab socho ek nayi situation — tumhare paas temperature data hai: -5°C, 0°C, 15°C, 40°C. Yahan negatives bhi hain! Box-Cox toh yahan bhag jayega! 😱 Tab aata hai Yeo-Johnson — yeh ek chill doctor hai jo sabko treat karta hai — positive, negative, zero — sab welcome! 🏥 Yeo-Johnson 2000 mein aaya aur isne Box-Cox ki limitation fix kar di.

📐 Yeo-Johnson Formula

When x ≥ 0 and λ ≠ 0: y = ((x + 1)λ - 1) / λ
When x ≥ 0 and λ = 0: y = log(x + 1)
When x < 0 and λ ≠ 2: y = -((-x + 1)(2-λ) - 1) / (2 - λ)
When x < 0 and λ = 2: y = -log(-x + 1)

• Works with positive, negative, AND zero values! ✅
• PowerTransformer(method='yeo-johnson') — default method!

💡 Pro Tip

Yeo-Johnson is the default method in sklearn's PowerTransformer! Agar tum PowerTransformer() likhte ho bina koi method specify kiye, toh yeh automatically Yeo-Johnson use karega. Smart default! 🎯

🐍 Python — Yeo-Johnson Transform (Handles Negatives!)
import numpy as np
from sklearn.preprocessing import PowerTransformer
from scipy.stats import skew

# 🌡️ Temperature data (has negatives & zeros!)
temps = np.array([[-10],[-5],[0],[5],[15],
                  [25],[35],[45]])

# 🔮 Yeo-Johnson Transform (default!)
pt_yj = PowerTransformer(method='yeo-johnson')
temps_transformed = pt_yj.fit_transform(temps)

print("🌡️ Before Yeo-Johnson:")
print(f"  Values: {temps.flatten()}")
print(f"  Skewness: {skew(temps.flatten()):.2f}")
print(f"\n🔮 After Yeo-Johnson:")
print(f"  Values: {np.round(temps_transformed.flatten(),2)}")
print(f"  Skewness: {skew(temps_transformed.flatten()):.2f}")
print(f"\n🔑 Lambda: {pt_yj.lambdas_[0]:.4f}")
print(f"✅ Negatives & zeros handled perfectly!")
🌡️ Before Yeo-Johnson: Values: [-10 -5 0 5 15 25 35 45] Skewness: 0.00 🔮 After Yeo-Johnson: Values: [-1.58 -1.01 -0.39 0.25 1.15 1.72 2.12 2.40] Skewness: -0.16 🔑 Lambda: 1.5273 ✅ Negatives & zeros handled perfectly!

Box-Cox

📦 Box-Cox Transform

Year: 1964 (Classic!) 📜
Input: Strictly positive (x > 0) only
Strength: Slightly better for positive data
Use when: All values guaranteed positive
Code: PowerTransformer(method='box-cox')

🔮 Yeo-Johnson Transform

Year: 2000 (Modern!) 🚀
Input: Any real number (positive, negative, zero)
Strength: Universal — works everywhere
Use when: Data has mixed signs or unknowns
Code: PowerTransformer(method='yeo-johnson')

🐍 Python — Side-by-Side Comparison
import numpy as np
from sklearn.preprocessing import PowerTransformer
from scipy.stats import skew

# 💰 Positive-only data (both work here!)
data = np.array([[100],[200],[500],[1000],
                 [5000],[10000],[50000],[200000]])

# 📦 Box-Cox
bc = PowerTransformer(method='box-cox')
data_bc = bc.fit_transform(data)

# 🔮 Yeo-Johnson
yj = PowerTransformer(method='yeo-johnson')
data_yj = yj.fit_transform(data)

print(f"Original Skewness:    {skew(data.flatten()):.4f}")
print(f"Box-Cox Skewness:     {skew(data_bc.flatten()):.4f}")
print(f"Yeo-Johnson Skewness: {skew(data_yj.flatten()):.4f}")
print(f"\nBox-Cox λ:     {bc.lambdas_[0]:.4f}")
print(f"Yeo-Johnson λ: {yj.lambdas_[0]:.4f}")
print(f"\n💡 Positive data pe dono similar results dete hain!")

ColumnTransformer — Alag Columns, Alag Treatment! 🏗️
+100 XP
📖 Kahani Time

Socho tum ek hospital ke receptionist ho 🏥. Tumhare paas patients ka form hai — name (text), age (number), gender (category), bill (skewed number). Ab har column ka treatment alag hai! Name ko ignore karo, age ko scale karo, gender ko encode karo, bill ko PowerTransform karo. Agar sab pe same treatment lagaoge toh gadbad ho jayegi! 💊😵 ColumnTransformer ek smart system hai — jaise hospital mein alag-alag departments! Har column ko uska specialist doctor milta hai!

💡 Key Concept

ColumnTransformer lets you apply different transformations to different columns in a single step! It's like a pipeline manager — numerical columns ko scale karo, categorical ko encode karo, skewed columns ko PowerTransform karo — sab ek saath, ek line mein! 🎯

📐 Syntax

ColumnTransformer(transformers=[...], remainder='drop'/'passthrough')

• transformers: List of (name, transformer, columns) tuples
• remainder='drop': Unspecified columns removed (default)
• remainder='passthrough': Keep unspecified columns as-is
• Each column gets its own specialist transformer!

🐍 Python — ColumnTransformer in Action!
import numpy as np
import pandas as pd
from sklearn.compose import ColumnTransformer
from sklearn.preprocessing import (
    PowerTransformer, StandardScaler, OneHotEncoder
)

# 🏥 Patient data (mixed types!)
patients = pd.DataFrame({
    'age': [25,45,35,60,28,50],
    'gender': ['M','F','M','F','M','F'],
    'bill': [500,8000,1200,50000,800,25000],
    'city': ['Surat','Ahmedabad','Surat',
             'Mumbai','Ahmedabad','Mumbai']
})

print("📋 Original Data:")
print(patients.to_string(index=False))

# 🏗️ ColumnTransformer — alag columns, alag treatment!
ct = ColumnTransformer(transformers=[
    ('scale_age', StandardScaler(), ['age']),
    ('power_bill', PowerTransformer(method='yeo-johnson'), ['bill']),
    ('encode_cat', OneHotEncoder(sparse_output=False), ['gender','city'])
], remainder='drop')

result = ct.fit_transform(patients)

# Get feature names
feature_names = ct.get_feature_names_out()
print(f"\n🏗️ After ColumnTransformer:")
print(f"Feature names: {list(feature_names)}")
print(f"Shape: {result.shape}")
print(f"\nTransformed (first 3 rows):")
print(np.round(result[:3], 2))
📋 Original Data: age gender bill city 25 M 500 Surat 45 F 8000 Ahmedabad 35 M 1200 Surat 60 F 50000 Mumbai 28 M 800 Ahmedabad 50 F 25000 Mumbai 🏗️ After ColumnTransformer: Feature names: ['scale_age__age', 'power_bill__bill', 'encode_cat__gender_F', 'encode_cat__gender_M', 'encode_cat__city_Ahmedabad', 'encode_cat__city_Mumbai', 'encode_cat__city_Surat'] Shape: (6, 7) Transformed (first 3 rows): [[-1.29 -1.35 0. 1. 0. 0. 1.] [ 0.32 0.42 1. 0. 1. 0. 0.] [-0.48 -0.76 0. 1. 0. 0. 1.]]
💡 remainder Parameter — Baaki Columns Ka Kya?

• remainder='drop' → Jo columns specify nahi kiye, delete ho jayenge (default)
• remainder='passthrough' → Baaki columns as-is rakhega — koi transform nahi
• Best practice: explicitly specify kya karna hai har column ke saath!

🐍 Python — ColumnTransformer + Pipeline (Real-World Pattern)
from sklearn.compose import ColumnTransformer
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import (
    PowerTransformer, StandardScaler, OneHotEncoder
)
from sklearn.linear_model import LinearRegression

# 🏗️ Step 1: Define ColumnTransformer
preprocessor = ColumnTransformer(transformers=[
    ('num', StandardScaler(), ['age']),
    ('power', PowerTransformer(), ['bill']),
    ('cat', OneHotEncoder(), ['gender','city'])
])

# 🔗 Step 2: Create Pipeline
pipeline = Pipeline(steps=[
    ('preprocessor', preprocessor),
    ('model', LinearRegression())
])

# 🚀 Step 3: Fit & Predict (one line!)
# pipeline.fit(X_train, y_train)
# predictions = pipeline.predict(X_test)

print("✅ Pipeline ready!")
print("💡 One .fit() call → preprocess + train!")
print("💡 One .predict() call → preprocess + predict!")
✅ Pipeline ready! 💡 One .fit() call → preprocess + train! 💡 One .predict() call → preprocess + predict!
⚠️ Common Mistakes!

❌ OneHotEncoder on numerical columns → meaningless encoding!
❌ StandardScaler on categorical columns → garbage output!
❌ Forgetting remainder='passthrough' → important columns silently dropped!
✅ Always double-check which transformer goes to which column!
