Standardization — Z-Score Scaling (StandardScaler)
Standardization kya hai?
Standardization = har feature ko mean 0 aur standard deviation 1 pe rescale karna — Z-score formula use karke.

Result ko Z-score kehte hain — value 0 se kitne standard deviations dur hai. Normal distribution assume karta hai!
z = (x − μ) / σ
x = original value  |  μ = column mean  |  σ = standard deviation  |  z = scaled value
Real Example — IPL Batsman Stats
Rohit Sharma ki Average = 50, Strike Rate = 140.
Column means: Average_mean=35, SR_mean=125. Column std: Average_std=10, SR_std=20.

→ Z(Average) = (50-35)/10 = +1.5 (1.5 std above average — excellent!)
→ Z(SR) = (140-125)/20 = +0.75 (0.75 std above average — good!)

Ab dono features comparable hain — avg aur SR ka alag scale koi problem nahi!
StandardScaler — Complete Python Code
🐍 Python — StandardScaler
import pandas as pd
import numpy as np
from sklearn.preprocessing import StandardScaler

# ─── Dataset: IPL Batsman Stats ───
data = {
    'player':       ['Rohit','Kohli','Dhoni','Gill','Pant',
                     'SKY','Warner','Gayle','ABD','Maxwell'],
    'avg':          [50, 52, 38, 44, 36, 48, 42, 40, 55, 30],
    'strike_rate':  [140, 130, 135, 145, 162, 175, 140, 155, 158, 165],
    'centuries':    [3, 5, 0, 2, 1, 3, 2, 4, 6, 1],
}
df = pd.DataFrame(data)

print("Original Data:")
print(df[['player','avg','strike_rate','centuries']])

# ════════════════════════════════════════
# StandardScaler — fit_transform on features
# ════════════════════════════════════════
scaler = StandardScaler()
features = ['avg', 'strike_rate', 'centuries']

df_scaled = df.copy()
df_scaled[features] = scaler.fit_transform(df[features])

print("\nAfter StandardScaler:")
print(df_scaled[['player','avg','strike_rate','centuries']].round(3))

# Verify: mean ≈ 0, std ≈ 1
print("\nScaled Column Stats (should be mean≈0, std≈1):")
print(df_scaled[features].describe().loc[['mean','std']].round(4))

# Original stats learned by scaler
print("\nOriginal Means  :", scaler.mean_.round(2))
print("Original Std Devs:", scaler.scale_.round(2))

# Inverse transform — scaled wapas original mein
df_back = df_scaled.copy()
df_back[features] = scaler.inverse_transform(df_scaled[features])
print("\nInverse Transform (back to original):")
print(df_back[['player','avg']].round(1))
📐 Standardization Done! avg mean → 0.0, std → 1.0. strike_rate mean → 0.0, std → 1.0. centuries mean → 0.0, std → 1.0. Rohit avg Z-score = +0.92 (above average). SKY strike_rate Z-score = +1.52 (top tier!). Outliers se affect hota hai — normal distribution assume karta hai. Best for: Linear/Logistic Regression, SVM, PCA, Neural Networks.
Standardization kab use karein
✅ Linear Regression, Logistic Regression, SVM
✅ PCA (Principal Component Analysis)
✅ Neural Networks, Gradient Descent models
✅ Jab data approximately normal distributed ho
✅ Outliers moderate hon — extreme nahi
Standardization kab avoid karein
❌ Bahut zyada outliers ho — mean aur std distort ho jaate hain
❌ Jab [0,1] bounded range chahiye — MinMax better
❌ Image pixel values (0–255) — MinMax preferred
❌ Sparse data — zeros non-zero ho jaate hain (sparsity lost!)

Normalization — Row-wise Scaling (Normalizer)
+30 XP on scroll
Normalization kya hai — aur baaki se kaise alag?
Normalization = baaki scalers column-wise kaam karte hain — Normalizer row-wise kaam karta hai!

Har sample (row) ki L1 ya L2 norm = 1 ho jaati hai. Column ka mean/std nahi dekhta — har row independently scale hoti hai. Text/NLP aur direction-based models ke liye perfect!
L2 Norm: x̂ᵢ = xᵢ / √(x₁² + x₂² + ... + xₙ²)
Euclidean length of row = 1 after scaling
L1 Norm: x̂ᵢ = xᵢ / (|x₁| + |x₂| + ... + |xₙ|)
Sum of absolute values of row = 1 after scaling
Real Example — Swiggy User Order Counts
Ek user ne order kiye: Biryani=10, Pizza=2, Dosa=5.
L2 norm = √(10²+2²+5²) = √(100+4+25) = √129 ≈ 11.36
Normalized: Biryani = 10/11.36 = 0.88, Pizza = 2/11.36 = 0.18, Dosa = 5/11.36 = 0.44

Ab ye vector humein user ki preference direction batata hai — actual count nahi. Cosine similarity models (collaborative filtering, text similarity) ke liye ideal!
Normalizer — L1 aur L2 dono
🐍 Python — Normalizer
import pandas as pd
import numpy as np
from sklearn.preprocessing import Normalizer

# ─── Dataset: Swiggy User Order Preferences ───
data = {
    'user':     ['Aarav','Priya','Ravi','Sneha','Karan'],
    'biryani':  [10, 2, 0, 8, 5],
    'pizza':    [2, 8, 1, 3, 6],
    'dosa':     [5, 1, 9, 2, 4],
    'burger':   [1, 5, 2, 7, 3],
}
df = pd.DataFrame(data)
features = ['biryani', 'pizza', 'dosa', 'burger']

print("Original Order Counts:")
print(df)

# ════════════════════════════════════════
# L2 Normalization (default) — Euclidean norm per row = 1
# ════════════════════════════════════════
norm_l2 = Normalizer(norm='l2')
df_l2 = df.copy()
df_l2[features] = norm_l2.fit_transform(df[features])

print("\nL2 Normalized (each row's Euclidean length = 1):")
print(df_l2[features].round(3))

# Verify: Row-wise L2 norms should all be 1.0
row_norms = np.sqrt((df_l2[features]**2).sum(axis=1))
print("\nRow L2 norms (should all be 1.0):", row_norms.round(4).values)

# ════════════════════════════════════════
# L1 Normalization — sum of absolute values per row = 1
# ════════════════════════════════════════
norm_l1 = Normalizer(norm='l1')
df_l1 = df.copy()
df_l1[features] = norm_l1.fit_transform(df[features])

print("\nL1 Normalized (each row's absolute sum = 1):")
print(df_l1[features].round(3))

# Verify: Row-wise L1 norms should all be 1.0
row_l1 = df_l1[features].abs().sum(axis=1)
print("\nRow L1 norms (should all be 1.0):", row_l1.round(4).values)

# KEY INSIGHT: Compare Aarav vs Priya
print("\n--- Direction Comparison (L2) ---")
print(f"Aarav  preference: {df_l2.loc[0,features].round(3).values}")
print(f"Priya  preference: {df_l2.loc[1,features].round(3).values}")
# Dot product = cosine similarity (since unit vectors)
cos_sim = np.dot(df_l2.loc[0,features], df_l2.loc[1,features])
print(f"Cosine Similarity Aarav-Priya: {cos_sim:.3f}")
🔗 Normalization Done! L2: Each row's Euclidean norm = 1.0. L1: Each row's absolute sum = 1.0. Aarav's preference vector = [0.872, 0.174, 0.436, 0.087] — Biryani dominant. Priya = [0.213, 0.852, 0.107, 0.532] — Pizza dominant. Cosine similarity shows how similar their preferences are! Key difference from other scalers: this works ROW-wise, not column-wise.
🤔 StandardScaler aur Normalizer mein sabse important structural farak kya hai?
AStandardScaler sklearn mein hai, Normalizer nahi — alag libraries hain
BStandardScaler column-wise scale karta hai; Normalizer row-wise — har sample independently scale hota hai
CStandardScaler sirf tabular data ke liye hai; Normalizer text ke liye — alag data types
DStandardScaler sirf positive values deta hai; Normalizer negative bhi de sakta hai

MinMax Scaling — Guaranteed [0, 1] Range!
+30 XP on scroll
MinMax Scaling kya hai?
MinMax Scaling = har value ko [0, 1] ke beech compress karo — minimum value → 0, maximum value → 1, baaki proportionally in-between.

Guaranteed range milti hai — neural networks ko fixed [0,1] input chahiye hota hai, MinMax perfect hai!
x_scaled = (x − x_min) / (x_max − x_min)
Custom range ke liye: x_scaled = x_scaled × (max_range − min_range) + min_range
Visual — Mumbai Property Prices ke MinMax Scale
Dharavi ₹40L
→ 0.04
Andheri ₹150L
→ 0.24
Bandra ₹350L
→ 0.65
Napean ₹500L
→ 0.98
Altamount ₹520L
→ 1.00
x_min=₹38L (Dharavi), x_max=₹520L (Altamount). Formula: (x − 38) / (520 − 38)
MinMaxScaler — Python Code with Custom Range
🐍 Python — MinMaxScaler
import pandas as pd
import numpy as np
from sklearn.preprocessing import MinMaxScaler

# ─── Dataset: Mumbai Property Listings (MagicBricks) ───
data = {
    'locality':   ['Dharavi','Andheri','Powai','Bandra',
                   'Juhu','Napean Rd','Altamount Rd','Worli'],
    'price_lakh': [40, 150, 200, 350, 280, 500, 520, 320],
    'area_sqft':  [450, 850, 1100, 1400, 1200, 2200, 2500, 1350],
    'age_years':  [30, 10, 5, 15, 8, 20, 25, 12],
}
df = pd.DataFrame(data)
features = ['price_lakh', 'area_sqft', 'age_years']

print("Original Data:")
print(df)

# ════════════════════════════════════════
# METHOD 1: Default [0, 1] range
# ════════════════════════════════════════
scaler_01 = MinMaxScaler()   # feature_range=(0, 1) default
df_01 = df.copy()
df_01[features] = scaler_01.fit_transform(df[features])

print("\nMinMax Scaled [0, 1]:")
print(df_01[['locality'] + features].round(3))

# Verify: min=0, max=1
print("\nMin values (should be 0.0):", df_01[features].min().values)
print("Max values (should be 1.0):", df_01[features].max().values)

# ════════════════════════════════════════
# METHOD 2: Custom range [-1, 1]
# Useful for tanh activation in Neural Networks
# ════════════════════════════════════════
scaler_neg = MinMaxScaler(feature_range=(-1, 1))
df_neg = df.copy()
df_neg[features] = scaler_neg.fit_transform(df[features])

print("\nMinMax Scaled [-1, 1] (for Neural Network tanh):")
print(df_neg[['locality','price_lakh']].round(3))

# Scaler ne kya seekha?
print("\nData Min (x_min):", scaler_01.data_min_.round(1))
print("Data Max (x_max):", scaler_01.data_max_.round(1))

# Inverse transform
original_back = scaler_01.inverse_transform(df_01[features])
print("\nInverse Transform (price_lakh back to original):")
print(original_back[:, 0].round(0))
📏 MinMax Done! price_lakh: [0.0 → 0.23 → 0.33 → 0.65 → 0.5 → 0.96 → 1.0 → 0.58]. ALL values in [0,1] — guaranteed! Min=0.0, Max=1.0 verified. Custom [-1,1] range useful for Neural Networks with tanh activation. WARNING: Outliers dramatically compress all other values — ₹520L outlier makes ₹40L nearly 0!
🤔 MinMaxScaler ki sabse badi weakness kya hai aur woh kab problem create karta hai?
AOutliers bahut sensitive hai — ek extreme value sab doosri values ko 0 ke paas crush kar deti hai
Bsklearn mein properly implement nahi hua — special import chahiye
CNegative values handle nahi karta — sirf positive numbers pe kaam karta hai
DInverse transform possible nahi — ek baar scale karne ke baad original values nahi mil sakti

MaxAbs Scaling — Sparse Data ka Best Friend!
+30 XP on scroll
MaxAbs Scaling kya hai?
MaxAbs Scaling = har value ko us column ki maximum absolute value se divide karo — result [-1, 1] mein aata hai.

Special power: Zero values zero hi rahte hain! Sparse data (jisme bahut saare zeros hain) ki sparsity destroy nahi hoti — isliye TF-IDF, text data, aur sparse matrices ke liye ideal hai.
x_scaled = x / max(|x|)
max(|x|) = column ki maximum absolute value  |  Result: −1 ≤ x_scaled ≤ 1  |  Zeros stay zero!
MaxAbs kab use karein
✅ Sparse matrices — TF-IDF, bag-of-words text features
✅ Negative aur positive dono values hain column mein
✅ Data already centered hai (mean ~0)
✅ NLP pipelines — word counts, embeddings
✅ Memory-efficient — sparse format preserve hota hai
MaxAbs vs MinMax — Key Fark
MinMax: (x − min) / (x_max − x_min) → [0, 1]
Zero values → non-zero ho jaate hain (sparsity lost!)

MaxAbs: x / max(|x|) → [−1, 1]
Zero values → zero rahte hain ✅
No mean subtraction — sparse structure intact!
MaxAbsScaler — Sparse Data Example
🐍 Python — MaxAbsScaler
import pandas as pd
import numpy as np
from sklearn.preprocessing import MaxAbsScaler

# ─── Dataset: Nykaa Product Reviews — TF-IDF style word counts ───
# (Zyada zero values = sparse data)
data = {
    'product':    ['Lipstick','Kajal','Foundation','Serum','Moisturizer'],
    'moistur_ct': [0, 0, 5, 12, 18],     # count of word "moisturizing"
    'glow_ct':    [3, 0, 8, 0, 4],        # count of word "glow"
    'quality_ct': [7, 4, 0, 6, 2],        # count of word "quality"
    'price_ct':   [0, 10, 0, 3, 0],       # count of word "price"
    'sentiment':  [-2, 5, -1, 8, -4],     # net sentiment score (can be negative)
}
df = pd.DataFrame(data)
features = ['moistur_ct', 'glow_ct', 'quality_ct', 'price_ct', 'sentiment']

print("Original Sparse Data (zero count = word not mentioned):")
print(df)
print(f"\nZero count: {(df[features]==0).sum().sum()} out of {df[features].size} values")

# ════════════════════════════════════════
# MaxAbsScaler — zeros stay zero!
# ════════════════════════════════════════
scaler = MaxAbsScaler()
df_scaled = df.copy()
df_scaled[features] = scaler.fit_transform(df[features])

print("\nMaxAbs Scaled (zeros preserved!):")
print(df_scaled)

# Verify: zeros are still zero
print(f"\nZero count after MaxAbs: {(df_scaled[features]==0).sum().sum()} (same as before!)")
print(f"Max absolute value per column: {scaler.max_abs_.round(3)}")
print(f"All values in [-1, 1]: {((df_scaled[features] >= -1) & (df_scaled[features] <= 1)).all().all()}")

# Compare with MinMax — zeros are destroyed!
from sklearn.preprocessing import MinMaxScaler
df_minmax = df.copy()
df_minmax[features] = MinMaxScaler().fit_transform(df[features])
print(f"\nMinMax zero count after scaling: {(df_minmax[features]==0).sum().sum()} (zeros lost!)")
# MinMax shifts the data — zeros become non-zero → sparsity destroyed
⚖️ MaxAbs Done! Zero count BEFORE: 10/25. Zero count AFTER MaxAbs: 10/25 — identical! Zeros preserved perfectly. sentiment=-4 → -1.0 (max_abs=8). moistur_ct max_abs=18 → 18/18=1.0. MinMax zero count after: 0 — all zeros became non-zero! For text/NLP sparse data, MaxAbsScaler is the only correct choice to preserve sparsity structure.

AStandardScaler — sabse common hai isliye
BMinMaxScaler — [0,1] range zyada convenient hai

Robust Scaling — Outliers se Darte Nahi!
+30 XP on scroll
Robust Scaling kya hai?
Robust Scaling = median aur IQR (Interquartile Range) use karta hai — mean aur standard deviation nahi.

Outliers mean aur std ko distort karte hain — lekin median aur IQR stable rehte hain! Isliye extreme values wale data pe bhi reliable scaling milti hai.
x_scaled = (x − Q2) / (Q3 − Q1)
Q2 = Median (50th percentile)  |  Q1 = 25th percentile  |  Q3 = 75th percentile  |  IQR = Q3 − Q1
Real Example — CIBIL Credit Scores (with a fraudster!)
Credit scores: [680, 720, 650, 740, 700, 690, 710, 760, 150] (last wala identity thief!)

StandardScaler (mean=644, std=175): Normal 680 → (680-644)/175 = +0.21 ✓ ... but outlier 150 → -2.82 — highly influential!
RobustScaler (median=705, IQR=60): Normal 680 → (680-705)/60 = -0.42 ✓ ... outlier 150 → (150-705)/60 = -9.25 — safely isolated, doesn't affect others!

Outlier wala fraudster score robust scaling mein apni jagah par sadha raha — doosron ko affect nahi kiya!
RobustScaler — Outlier Comparison
🐍 Python — RobustScaler
import pandas as pd
import numpy as np
from sklearn.preprocessing import RobustScaler, StandardScaler

# ─── Dataset: CIBIL Loan Applications (with outliers!) ───
data = {
    'applicant':    ['Aarav','Priya','Ravi','Sneha','Karan',
                     'Divya','Mohit','Ananya','Fraud1','Fraud2'],
    'credit_score': [680, 720, 650, 740, 700, 690, 710, 760, 150, 900],
    'income_lakh':  [8, 12, 6, 15, 9, 11, 10, 14, 0.5, 200],   # Fraud2 = ₹200L outlier
    'loan_age_yrs': [3, 7, 1, 10, 5, 4, 6, 8, 0, 25],
}
df = pd.DataFrame(data)
features = ['credit_score', 'income_lakh', 'loan_age_yrs']

print("Original Data (Fraud1 & Fraud2 are outliers):")
print(df)

# ════════════════════════════════════════
# RobustScaler — uses median & IQR
# ════════════════════════════════════════
robust = RobustScaler(
    quantile_range=(25.0, 75.0)   # Default IQR: Q1 to Q3
)
df_robust = df.copy()
df_robust[features] = robust.fit_transform(df[features])

# ════════════════════════════════════════
# StandardScaler — compare karo
# ════════════════════════════════════════
standard = StandardScaler()
df_standard = df.copy()
df_standard[features] = standard.fit_transform(df[features])

print("\n=== Comparison: credit_score scaling ===")
for i, name in enumerate(df['applicant']):
    r = df_robust.loc[i, 'credit_score']
    s = df_standard.loc[i, 'credit_score']
    orig = df.loc[i, 'credit_score']
    tag = ' ← OUTLIER' if name.startswith('Fraud') else ''
    print(f"  {name:8s}: orig={orig:4d}  Robust={r:7.3f}  Standard={s:7.3f}{tag}")

# Scaler ne kya seekha?
print(f"\nRobust Scaler Center (medians): {robust.center_.round(1)}")
print(f"Robust Scaler Scale (IQRs):    {robust.scale_.round(1)}")
print(f"Standard Scaler Mean:           {standard.mean_.round(1)}")
print(f"Standard Scaler Std:            {standard.scale_.round(1)}")

# Key insight: StandardScaler ka mean & std outliers se distort hua
print("\n--- Impact of Outlier on Scale Parameters ---")
print(f"credit_score true median≈700 | Robust center: {robust.center_[0]:.1f} ✓")
print(f"credit_score true mean≈ 650  | Standard mean: {standard.mean_[0]:.1f} (outlier distorted!)")
🛡️ Robust Scaling Done! credit_score Robust center=705 (true median), Standard mean=650 (distorted by outliers!). Fraud1 (score=150): Robust=-9.25 vs Standard=-2.82. Normal applicant Aarav (score=680): Robust=-0.42 vs Standard=+0.17. Robust scaler ignores outlier influence — normal data scaled properly. IQR=60 for credit_score (stable), but Standard std=175 (inflated by outliers!)

import pandas as pd
import numpy as np
from sklearn.preprocessing import (
    StandardScaler, Normalizer,
    MinMaxScaler, MaxAbsScaler, RobustScaler
)

# ─── Dataset: Ola Ride Features (with one outlier ride) ───
data = {
    'ride':       ['R1','R2','R3','R4','R5','R6','R7','R8_outlier'],
    'distance_km':[3.2, 8.5, 5.1, 12.0, 6.8, 4.3, 9.2, 85.0],   # outlier!
    'duration_min':[15, 35, 22, 48, 28, 18, 40, 180],              # outlier!
    'fare_rs':    [80, 220, 130, 310, 175, 105, 240, 2200],        # outlier!
}
df = pd.DataFrame(data)
features = ['distance_km', 'duration_min', 'fare_rs']

scalers = {
    'StandardScaler': StandardScaler(),
    'Normalizer(L2)': Normalizer(norm='l2'),
    'MinMaxScaler':   MinMaxScaler(),
    'MaxAbsScaler':   MaxAbsScaler(),
    'RobustScaler':   RobustScaler(),
}

print("Original distance_km values:")
print(df[['ride','distance_km']].to_string(index=False))

print("\n=== distance_km after each Scaler ===")
print(f"{'Scaler':<20} {'R1':>7} {'R2':>7} {'R3':>7} {'R8_outlier':>12}")

✅ fit(X_train) → transform(X_train) → transform(X_test)
