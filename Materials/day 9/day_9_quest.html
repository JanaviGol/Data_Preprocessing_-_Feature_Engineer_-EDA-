Mixed Variables — Ek Column, Do Duniya!
+30 XP on scroll
Core Idea — Ek Line Mein
Mixed Variable = ek column jisme numbers aur text dono saath hote hain — ya jisme ek hi type ke andar do alag meanings hoti hain.

Real life mein ye bahut common hai — "100", "200+", "N/A", "Unknown", "300 km" — yeh sab ek hi column mein aa jaate hain aur ML model inhe directly nahi samjh sakta!
Mixed Variables ke 3 Common Types
①
Number + String Mix
['100', '200+', 'N/A', '150', 'Unknown']
Column mein mostly numbers hain, lekin kuch special string values bhi hain — "200+" ka matlab "200 se zyada", "N/A" ka matlab missing.
Example: Paytm transactions — kuch "Pending", kuch ₹ amount
②
Number + Unit Mix
['5 km', '10 km', '3.5 km', '8 km']
Value ke saath unit bhi string mein hai. Pandas ise string maanega — numeric operations nahi ho sakti seedha.
Example: Ola/Uber distance column — "4.2 km" as string
③
Code + Category Mix
['A100', 'B200', 'A150', 'C300', 'B180']
Value mein ek letter (category) aur number dono hain. Inhe alag karna padta hai — letter ek feature, number dusra feature.
Example: Product code "A100" — A=category, 100=SKU number
Real India Examples — Mixed Variables Pehchano
🚗 Ola/Uber distance: "4.2 km", "10 km", "N/A"
💊 Pharmacy dosage: "500mg", "1g", "250 mg"
🏠 Property area: "1200 sqft", "2 BHK", "1.5 acres"
💳 Paytm transaction: "500", "Pending", "Refunded"
📦 Swiggy weight: "200g", "0.5 kg", "1 kg"
📱 JioFiber speed: "100 Mbps", "Unlimited", "1 Gbps"
Problem — ML Model Ke Saath
df['distance'].mean() — Error! "4.2 km" ek string hai, number nahi.
df['amount'].sum() — Wrong! "Pending" aur "500" ek saath sum nahi ho sakta.

Solution: Mixed variables ko clean karo → numbers extract karo → categories alag column mein lo → ML-ready format mein convert karo!
🤔 Ek Swiggy dataset mein "delivery_distance" column hai: ["3.2 km", "5 km", "N/A", "8.1 km", "Cancelled"]. Ye column kaunse type ka mixed variable hai aur iska kya problem hai?
APure categorical variable hai — koi problem nahi
BPure numerical variable hai — seedha use kar sakte hain
CNumber+String mix hai — unit aur special values ko alag handle karna padega
DBoolean variable hai — True/False mein convert karo

🐍 Python — Mixed Variables
import pandas as pd
import numpy as np

# ─── Inline Dataset: Ola Ride Records ───
data = {
    'ride_id':   [101, 102, 103, 104, 105, 106, 107, 108],
    'distance':  ['3.2 km', '5 km', 'N/A', '8.1 km',        # Number + Unit + Special
                  'Cancelled', '12.5 km', '2 km', '6.8 km'],
    'fare':      ['120', '200', 'Pending', '310',             # Number + String
                  'Refunded', '450', '90', '250'],
    'product_code': ['A100', 'B200', 'A150', 'C300',         # Code + Category mix
                     'B180', 'A200', 'C100', 'B250'],
}
df = pd.DataFrame(data)

print("Original Data:")
print(df)
print("\nData Types:")
print(df.dtypes)

# ════════════════════════════════════════
# FIX 1: distance column — unit hatao, number nikalo
# Approach: str.replace() se ' km' hatao, phir pd.to_numeric se convert karo
# ════════════════════════════════════════
# Step 1: ' km' text hatao
df['distance_clean'] = df['distance'].str.replace(' km', '', case=False)
# Step 2: Special words (N/A, Cancelled) ko NaN kar do
special_vals = ['N/A', 'Cancelled', 'Unknown', '']
df['distance_clean'] = df['distance_clean'].apply(
    lambda x: np.nan if x in special_vals else x
)
# Step 3: pd.to_numeric — jo bhi valid number hai woh float banega, baaki NaN
df['distance_km'] = pd.to_numeric(df['distance_clean'], errors='coerce')

# ════════════════════════════════════════
# FIX 2: fare column — numeric convert karo
# pd.to_numeric se: '120' → 120.0 | 'Pending' → NaN (errors='coerce')
# ════════════════════════════════════════
df['fare_num'] = pd.to_numeric(df['fare'], errors='coerce')
# 'Pending', 'Refunded' automatically NaN ho jaate hain!

# ════════════════════════════════════════
# FIX 3: product_code — category aur number alag karo
# 'A100' → category='A', number=100
# str[0] = pehla character (letter), str[1:] = baaki (number)
# ════════════════════════════════════════
df['product_category'] = df['product_code'].str[0]       # 'A100' → 'A'
df['product_num']      = pd.to_numeric(df['product_code'].str[1:])  # 'A100' → 100

# ════════════════════════════════════════
# FINAL RESULT
# ════════════════════════════════════════
# Temporary column drop karo
df.drop(columns=['distance_clean'], inplace=True)

print("\nCleaned Dataset:")
print(df[['ride_id','distance_km','fare_num','product_category','product_num']])
print("\nNew Data Types:")
print(df[['distance_km','fare_num','product_num']].dtypes)
🔀 Mixed Variables Cleaned! distance_km: float64 (N/A → NaN, Cancelled → NaN). fare_num: float64 (Pending/Refunded → NaN automatically via pd.to_numeric). product_category: A/B/C strings (str[0]). product_num: 100/200/150 floats (str[1:]). Ab ye sab ML mein use ho sakta hai!

🐍 Python — Date & Time Features
import pandas as pd
import numpy as np

# ─── Inline Dataset: Swiggy Orders ───
data = {
    'order_id':  [1001, 1002, 1003, 1004, 1005, 1006, 1007, 1008],
    'order_time': ['2024-01-15 13:30:00', '2024-03-22 20:15:00',
                   '2024-06-10 08:45:00', '2024-10-25 19:00:00',
                   '2024-12-25 12:00:00', '2024-04-07 22:30:00',
                   '2024-08-15 07:15:00', '2024-11-01 15:45:00'],
    'city':      ['Mumbai', 'Delhi', 'Bangalore', 'Hyderabad',
                  'Chennai', 'Pune', 'Kolkata', 'Ahmedabad'],
    'amount':    [350, 520, 180, 430, 850, 290, 620, 410],
}
df = pd.DataFrame(data)

# ════════════════════════════════════════
# STEP 1: String → datetime convert karo
# ════════════════════════════════════════
df['order_time'] = pd.to_datetime(df['order_time'])
print("Data type after conversion:", df['order_time'].dtype)
# datetime64[ns]

# ════════════════════════════════════════
# STEP 2: Basic date features nikalo
# ════════════════════════════════════════
df['year']     = df['order_time'].dt.year        # 2024
df['month']    = df['order_time'].dt.month       # 1-12
df['day']      = df['order_time'].dt.day         # 1-31
df['quarter']  = df['order_time'].dt.quarter     # 1-4
df['weekday']  = df['order_time'].dt.dayofweek   # 0=Mon, 6=Sun
df['week_num'] = df['order_time'].dt.isocalendar().week.astype(int)

# ════════════════════════════════════════
# STEP 3: Time features nikalo
# ════════════════════════════════════════
df['hour']   = df['order_time'].dt.hour    # 0-23
df['minute'] = df['order_time'].dt.minute  # 0-59

# ════════════════════════════════════════
# STEP 4: Derived / Business features banao
# ════════════════════════════════════════
# Weekend flag
df['is_weekend'] = df['weekday'].isin([5, 6]).astype(int)  # 5=Sat, 6=Sun

# Time of day category
def time_of_day(hour):
    if 5 <= hour < 12:   return 'Morning'
    elif 12 <= hour < 17: return 'Afternoon'
    elif 17 <= hour < 21: return 'Evening'
    else:                 return 'Night'

df['time_of_day'] = df['hour'].apply(time_of_day)

# Indian Season (roughly)
def indian_season(month):
    if month in [3, 4, 5]:   return 'Summer'
    elif month in [6, 7, 8, 9]: return 'Monsoon'
    elif month in [10, 11]:  return 'Autumn'
    else:                    return 'Winter'  # 12, 1, 2

df['season'] = df['month'].apply(indian_season)

# Days since a reference date
reference_date = pd.Timestamp('2024-01-01')
df['days_since_newyear'] = (df['order_time'] - reference_date).dt.days

# ════════════════════════════════════════
# RESULT
# ════════════════════════════════════════
print("\nExtracted Features:")
print(df[['order_id','month','weekday','hour','is_weekend',
          'time_of_day','season','days_since_newyear']].to_string())
📅 Ek timestamp se 10+ features! Christmas order (Dec 25, hour=12) → Winter, Afternoon, is_weekend=1, days_since_newyear=359. Independence Day (Aug 15, hour=7) → Monsoon, Morning. Ab ML model in patterns se seekhega!

Real India Example — HDFC Loan Applications
HDFC ke 10,000 loan applications hain. 800 applications mein kuch fields missing hain (income, CIBIL score, employment type).

CCA apply karo: Sirf woh 9,200 applications use karo jinmein sab kuch filled hai. 800 incomplete applications delete!

Kab sahi hai? Agar 800 applications randomly incomplete hain (MCAR) aur 9,200 remaining still large enough dataset hai — CCA perfect!
Kab galat hai? Agar sirf low-income applicants hi income field chhod rahe hain (MNAR) — toh CCA biased model banayega!
CCA ke Fayde
✅ Extremely simple — ek line code: df.dropna()
✅ No information "fabricated" — real data sirf
✅ Unbiased estimates jab MCAR ho
✅ ML models ke saath directly compatible
✅ Debugging easy — no imputed values to explain
CCA ki Limitations
❌ Data loss — chhota dataset aur zyada hua!
❌ Agar MNAR hai toh biased model banega
❌ Bahut zyada NaN → almost koi row nahi bachegi
❌ Incomplete rows mein bhi useful info thi
❌ Small datasets mein nuksandaayak
🤔 Complete Case Analysis kab BEST kaam karta hai?
AJab missing data MCAR ho, missing % kam ho (<10%), aur dataset bada ho
BJab missing data MNAR ho — sabse acha result deta hai
CJab 50%+ rows mein missing values hon
DChhote datasets mein — data loss minimal hota hai

🐍 Python — CCA / dropna()
import pandas as pd
import numpy as np

# ─── Inline Dataset: Student Exam Records ───
data = {
    'student':  ['Aarav','Priya','Ravi','Sneha','Karan',
                 'Divya','Mohit','Ananya','Vikram','Pooja'],
    'age':      [22, np.nan, 25, 23, np.nan, 21, 24, np.nan, 26, 20],
    'marks':    [85, 90, np.nan, 78, 88, np.nan, 72, 95, 80, np.nan],
    'city':     ['Mumbai','Delhi', np.nan,'Surat','Mumbai',
                 np.nan,'Delhi','Pune','Bangalore','Chennai'],
    'attendance':[90, 85, 80, np.nan, 92, 88, np.nan, 95, 78, 85],
}
df = pd.DataFrame(data)

print("Original Dataset:")
print(df)
print(f"\nShape: {df.shape}")
print(f"\nMissing values per column:\n{df.isnull().sum()}")
print(f"\nRows with at least one NaN: {df.isnull().any(axis=1).sum()}")

# ════════════════════════════════════════
# METHOD 1: All NaN rows hatao (basic CCA)
# ════════════════════════════════════════
df_cca = df.dropna()
print(f"\n--- Basic CCA (dropna all) ---")
print(f"Rows before: {len(df)} | Rows after: {len(df_cca)}")
print(df_cca)

# ════════════════════════════════════════
# METHOD 2: Specific columns pe CCA
# sirf marks aur age missing ho toh hi drop karo
# ════════════════════════════════════════
df_cca2 = df.dropna(subset=['marks', 'age'])
print(f"\n--- CCA on specific columns (marks + age) ---")
print(f"Rows before: {len(df)} | Rows after: {len(df_cca2)}")

# ════════════════════════════════════════
# METHOD 3: Threshold — agar 2+ columns NaN hain toh drop
# ════════════════════════════════════════
# thresh=3 means: kam se kam 3 non-NaN values chahiye row mein
df_cca3 = df.dropna(thresh=3)
print(f"\n--- CCA with thresh=3 ---")
print(f"Rows before: {len(df)} | Rows after: {len(df_cca3)}")

# ════════════════════════════════════════
# BEFORE vs AFTER — Statistics Check
# ════════════════════════════════════════
print("\n--- Before vs After: marks column ---")
print(f"Mean BEFORE: {df['marks'].mean():.2f}")
print(f"Mean AFTER:  {df_cca['marks'].mean():.2f}")
print(f"Missing %:   {df.isnull().sum().sum() / df.size * 100:.1f}% original")
print(f"Missing %:   {df_cca.isnull().sum().sum() / df_cca.size * 100:.1f}% after CCA")
🧹 CCA Results: Basic dropna() = 10 → 4 rows (60% loss!). Specific columns (marks+age) = 10 → 6 rows. thresh=3 = 10 → 8 rows. Missing % after = 0.0%! Lekin 10 mein se 4 sirf bachne pe — yeh dataset chhota tha, CCA aggressive tha!

Decision Framework — 3 Questions Puchho
Missingness MCAR hai kya?
Agar haan → CCA safe hai. Agar MNAR (rich log income nahi batate) → CCA mat karo, imputation karo!
Check: missing values ka koi pattern hai? Kisi specific group ke liye zyada missing hai?
Missing % kitna hai?
< 5%: CCA safe — loss negligible hai.
5–15%: CCA caution ke saath — dataset size pe depend karta hai.
> 15%: Imputation better — CCA se bahut data jayega.
Dataset kitna bada hai?
1 lakh+ rows: 5% delete karna = 5000 rows — still plenty data.
200 rows: 5% delete karna = 10 rows — significant loss!
Chhote datasets mein hamesha imputation prefer karo.
🤔 Ek Zomato dataset mein 50,000 orders hain. 2,500 orders mein "delivery_time" missing hai. Investigation se pata chala ki sirf rainy days pe delivery time nahi record hota (sensor fault). Kaunsa approach best hai?
ACCA — df.dropna() se 2500 rows hata do, 47500 kafi hain
BMissing Indicator add karo aur chod do
CDelivery time ko 0 se fill karo
DImputation — kyunki missingness MAR hai (rain-related pattern), CCA biased model banega

import pandas as pd
import numpy as np

# ─── Inline Dataset: Ola Rides with all problem types ───
data = {
    'ride_id':   [101, 102, 103, 104, 105, 106, 107, 108, 109, 110],
    'booking_time': ['2024-03-15 08:30:00','2024-06-22 14:15:00',
                     '2024-10-05 20:00:00','2024-01-18 07:45:00',
                     None,                 '2024-08-11 18:30:00',
                     '2024-12-25 11:00:00','2024-04-30 16:20:00',
                     '2024-09-01 09:10:00','2024-07-14 21:45:00'],
    'distance':  ['5.2 km','8 km','N/A','12.5 km','3.8 km',
                  'Cancelled','6.1 km','9.3 km',None,'4.7 km'],
    'fare':      ['180','250','Pending','420','140',
                  'Refunded','210','310',None,'165'],
    'rating':    [4.5, None, 4.2, 4.8, 4.0, None, 4.7, 4.3, 4.6, None],
    'city':      ['Mumbai','Delhi',None,'Pune','Bangalore',
                  'Mumbai','Chennai',None,'Hyderabad','Kolkata'],
}
df = pd.DataFrame(data)

print("=== STEP 1: Original Dataset ===")
print(df)
print(f"\nShape: {df.shape}")
print(f"Missing values:\n{df.isnull().sum()}")

# ════════════════════════════════
# STEP 2: Date-Time Handle karo
# ════════════════════════════════
df['booking_time'] = pd.to_datetime(df['booking_time'], errors='coerce')
df['hour']         = df['booking_time'].dt.hour
df['month']        = df['booking_time'].dt.month
df['is_weekend']   = df['booking_time'].dt.dayofweek.isin([5,6]).astype('Int64')

print("\n=== STEP 2: DateTime Features Added ===")
print(df[['ride_id','hour','month','is_weekend']].head())

# ════════════════════════════════
# STEP 3: Mixed Variables Clean karo
# Simple approach: str.replace + pd.to_numeric
# ════════════════════════════════

# distance: ' km' text hatao, special values NaN, phir numeric convert
special_vals = ['N/A', 'Cancelled', 'Refunded', 'Pending', 'Unknown', '']

df['distance_clean'] = df['distance'].str.replace(' km', '', case=False)
df['distance_clean'] = df['distance_clean'].apply(
    lambda x: np.nan if x in special_vals else x
)
df['distance_km'] = pd.to_numeric(df['distance_clean'], errors='coerce')

# fare: sirf pd.to_numeric — 'Pending', 'Refunded' automatically NaN ho jaate
df['fare_num'] = pd.to_numeric(df['fare'], errors='coerce')

# Cleanup temporary column
df.drop(columns=['distance_clean'], inplace=True)

print("\n=== STEP 3: Mixed Variables Cleaned ===")
print(df[['ride_id','distance_km','fare_num']])

# ════════════════════════════════
# STEP 4: CCA — Complete Case Analysis
# sirf core columns pe apply karo
# ════════════════════════════════
core_cols = ['distance_km', 'fare_num', 'rating', 'city', 'hour']
df_clean = df.dropna(subset=core_cols)

print(f"\n=== STEP 4: CCA Applied ===")
print(f"Rows before CCA: {len(df)}")
print(f"Rows after  CCA: {len(df_clean)}")
print(f"\nFinal Clean Dataset:")
print(df_clean[['ride_id','distance_km','fare_num',
                'rating','city','hour','month','is_weekend']])
✅ Full Pipeline Done! DateTime features extracted (hour, month, is_weekend). Mixed variables cleaned — str.replace(' km','') + pd.to_numeric(errors='coerce') — no regex needed! (distance_km, fare_num — numbers only). CCA applied on core columns: 10 → 5 clean rows. Ab ye data ML model ke liye ready hai — no mixed types, no NaN in important columns!
