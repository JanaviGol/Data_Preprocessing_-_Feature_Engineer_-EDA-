Feature Construction — Existing Data se Nayi Power Banao!
+30 XP on scroll
Core Idea — Ek Line Mein
Feature Construction = existing columns ko combine, manipulate ya transform karke nayi meaningful features banana — taaki model zyada useful information se seekhe.

Jaise date_of_birth se age nikalna, ya price aur discount se final_price banana. Ye ML mein ek super power hai!
Kyun Zaroori Hai? — 4 Strong Reasons
✅ Domain knowledge encode karna: Model ko directly business logic de do — price per sqft calculate karke
✅ Hidden patterns reveal karna: BMI = weight/height² — doctors ka knowledge ML mein daalo
✅ Model performance badhana: Raw features se jo nahi seekha, constructed features se seekhega
✅ Interactions capture karna: Age × Income ka combined effect — dono separately se better
Feature Construction ke 4 Main Types
➕
Arithmetic Features
Columns ko add, subtract, multiply, divide karo. Seedha aur sabse common!
df['a'] + df['b']
📅
Datetime Features
Date se year, month, day, weekday nikalo. Time-based patterns pakdne ke liye!
.dt.month
📝
Text-based Features
String se length, word count, patterns nikalo. NLP preprocessing mein essential!
.str.len()
🔗
Interaction Features
Do ya zyada features ka combination — multiplicative effects capture karo!
df['a'] * df['b']
Real India Examples — Har Jagah Feature Construction Hoti Hai
🏠 MagicBricks: price_per_sqft = price / area
💰 Flipkart: discount_pct = (mrp - price) / mrp * 100
🏥 Hospital: bmi = weight / (height ** 2)
🚗 Ola: surge = demand / supply
🏏 IPL: economy = runs / (overs)
📱 Paytm: avg_txn = total_amount / txn_count

Feature Splitting — Ek Column ko Tod ke Nayi Power Nikalo!
Feature Splitting kya hai?
Feature Splitting = ek column mein chhupa hua multiple information alag alag columns mein tod do — taaki model har piece of information ko independently use kar sake.

Jaise "Ahmedabad, Gujarat" se city = "Ahmedabad" aur state = "Gujarat" alag karna. Ek column mein 2 features chhupe the!
Common Splitting Scenarios
📍 Address: City, State, PIN alag karo
📅 DateTime: Date aur Time alag karo
👤 Full Name: First aur Last name alag karo
📞 Phone: Country code aur number alag karo
🏷️ Product Code: Category aur ID alag karo
Splitting ke Main Tools
🔧 .str.split() — delimiter se split
🔧 .str.extract() — regex se exact pattern
🔧 .str.get() — split ke baad index se lena
🔧 pd.json_normalize() — JSON column split karo
🔧 .str.partition() — pehle delimiter pe split

FunctionTransformer — Apni Custom Function ko Pipeline mein Daalo!
+30 XP on scroll
FunctionTransformer kya hai?
FunctionTransformer = scikit-learn ka ek wrapper jo kisi bhi Python function ko sklearn-compatible transformer mein convert karta hai — jise aap Pipeline mein directly use kar sako.

Aap np.log1p, np.sqrt, ya koi bhi custom lambda ya function pass karo — ye usse Pipeline-ready bana deta hai!
FunctionTransformer ke Advantages
✅ Koi bhi custom numpy/python function use karo
✅ Pipeline mein seamlessly fit hota hai
✅ inverse_func pass karke inverse transform bhi possible
✅ validate=True se input validation automatic
✅ Cross-validation aur GridSearchCV ke saath kaam karta hai
Basic Syntax
from sklearn.preprocessing import FunctionTransformer

transformer = FunctionTransformer(
  func=np.log1p,     # forward function
  inverse_func=np.expm1 # reverse function
)

transformer.fit_transform(X)
python 
import numpy as np
import pandas as pd
from sklearn.preprocessing import FunctionTransformer
from sklearn.pipeline import Pipeline

# Sample skewed salary data (in lakhs)
salaries = np.array([[2], [5], [8], [15], [25], [50], [120], [300]])

# ✅ Method 1: Direct usage
log_transformer = FunctionTransformer(func=np.log1p, inverse_func=np.expm1)
log_salaries = log_transformer.fit_transform(salaries)

print("Original:", salaries.flatten())
print("Log+1:   ", log_salaries.flatten().round(3))

# ✅ Method 2: Custom function in FunctionTransformer
def add_noise(X, noise_level=0.01):
    return X + np.random.normal(0, noise_level, X.shape)

custom_t = FunctionTransformer(func=add_noise,
                               kw_args={'noise_level': 0.05})

# ✅ Method 3: Inside a Pipeline (most powerful use!)
from sklearn.linear_model import LinearRegression

pipeline = Pipeline([
    ('log_transform', FunctionTransformer(np.log1p)),
    ('model', LinearRegression())
])
print("\nPipeline ready!")
print("Steps:", [step[0] for step in pipeline.steps])

Log Transform — Right-Skewed Data ko Normal Banao!
Log Transform kya hai?
Log Transform = har value ka logarithm lete hain — ye large values ko compress karta hai aur small values ko relatively preserve karta hai. Right-skewed distributions ko near-normal banata hai.

Formula: x_new = log(x) ya safer version x_new = log(x + 1) (np.log1p) — kyunki log(0) undefined hai!

Original Value

log1p(1000000)
13.82

10x difference (1L → 10L) log mein sirf 2.3 units ka difference! Outliers ka dominance khatam 🎯

Kab Use Karein — Log Transform
✅ Right-skewed data: Income, salary, property prices
✅ Exponential growth data: Population, viral spread
✅ Wide range data: Values 1 se 10 lakh tak
✅ Multiplicative relationships: jab % change meaningful ho
✅ Linear regression assumptions satisfy karne ke liye
Kab Avoid Karein — Log Transform
❌ Zero values: log(0) = -infinity! (log1p use karo)
❌ Negative values: log undefined for negatives
❌ Already normal data: log zyada skew kar sakta hai
❌ Left-skewed data: log aur skew badha dega
❌ Tree-based models ke liye (unhe transform ki zaroorat nahi)

import numpy as np
import pandas as pd
from sklearn.preprocessing import FunctionTransformer

# Real India example: House prices in Mumbai (lakhs)
df = pd.DataFrame({

})

)

df['price_log'] = log_transformer.fit_transform(df[['price_lakh']])

print(f"Log transformed   : {df['price_log'].skew():.3f}")
print()

Reciprocal Transform — 1/x se Relationships Flip Karo!
+30 XP on scroll
Reciprocal Transform kya hai?
Reciprocal Transform = har value ko uski reciprocal (ulta) se replace karo — yaani x_new = 1/x. Ye very large values ko very small aur very small values ko very large bana deta hai.

Practical use case: speed = distance / time mein time ka reciprocal = speed directly. Ya heavy-right-skewed distributions ko normalize karna.

Reciprocal ke Use Cases
✅ Time measurements: Response time ko throughput mein convert
✅ Rates aur ratios: 1/distance = proximity score
✅ Extreme right skew: Jab log bhi kaafi nahi hota
✅ Physics-based features: Resistance = 1/Conductance
✅ Jab inverse relationship model karna ho
Important Warnings
❌ Zero values: 1/0 = infinity — hamesha check karo!
❌ Negative values: Sign flip ho jaata hai — order badal sakta hai
❌ Values near zero: Extreme outliers create ho sakte hain
❌ Interpretation mushkil ho jaati hai
💡 Safe formula: 1 / (x + epsilon)
python 
import numpy as np
import pandas as pd
from sklearn.preprocessing import FunctionTransformer

# Real India use case: Delivery time to response rate
df = pd.DataFrame({
    'delivery_days': [1, 2, 3, 5, 7, 10, 15, 30, 60, 90],
    'hospital_name': ['AIIMS', 'Apollo', 'Fortis', 'Max', 'Narayana',
                      'Medanta', 'Wockhardt', 'Ruby Hall', 'Manipal', 'KEM']
})

# ✅ Reciprocal Transform using FunctionTransformer
def safe_reciprocal(X):
    return 1.0 / (X + 1e-8)   # add tiny epsilon to avoid division by zero

reciprocal_t = FunctionTransformer(func=safe_reciprocal)

df['delivery_speed_score'] = reciprocal_t.fit_transform(
    df[['delivery_days']]
)

# Normalize to 0-100 for readability
df['speed_score_pct'] = (
    (df['delivery_speed_score'] / df['delivery_speed_score'].max()) * 100
).round(1)

print("Delivery Days → Speed Score (higher = faster):")
print(df[['hospital_name', 'delivery_days', 'speed_score_pct']].to_string(index=False))

Square Root Transform — Gentle Compression for Moderate Skew!
Square Root Transform kya hai?
Square Root Transform = har value ka square root lete hain — x_new = √x. Ye Log transform se weaker hota hai — gentle compression karta hai. Moderate skew ke liye best choice!

Useful jab data mein zeros ya near-zero values hain (sqrt(0) = 0, log(0) = error), ya jab count data ho jaise Poisson-distributed data. 
flowchart LR

  B -->|"Moderate\n(1 - 2)"| D["√x\nSquare Root"]
  B -->|"High\n(2 - 3)"| E["log(x+1)\nLog Transform"]
  B -->|"Very High\n(> 3)"| F["1/x\nReciprocal"]

  E --> G
  F --> G
🌱
Sqrt — Gentle
Moderate compression. Zeros allowed! Count data ke liye perfect.
Formula: √x
🔨
Log — Moderate
Stronger compression. No zeros (use log1p). Income, price data.
Formula: log(x+1)
💥
Reciprocal — Aggressive
Strongest compression. No zeros (use epsilon). Extreme outliers.
Formula: 1/x

import numpy as np
import pandas as pd
from sklearn.preprocessing import FunctionTransformer

# Count data example: Customer complaints per branch (Poisson-like)
df = pd.DataFrame({
    'branch': [f'Branch_{i}' for i in range(1, 11)],
    'complaints': [0, 1, 2, 4, 6, 9, 15, 22, 45, 120]
})

print(f"Original skewness : {df['complaints'].skew():.3f}")

# ✅ Square Root Transform using FunctionTransformer
sqrt_transformer = FunctionTransformer(
    func=np.sqrt,
    inverse_func=np.square,  # inverse: x^2

)

df['complaints_sqrt'] = sqrt_transformer.fit_transform(df[['complaints']])

print(f"Sqrt skewness     : {df['complaints_sqrt'].skew():.3f}")
print()

df['complaints_log']  = np.log1p(df['complaints'])
df['complaints_recip'] = 1 / (df['complaints'] + 1)

print("Comparison Table:")

import numpy as np
import pandas as pd
from sklearn.preprocessing import FunctionTransformer, StandardScaler
from sklearn.pipeline import Pipeline
from sklearn.linear_model import Ridge
from sklearn.model_selection import train_test_split

# Full Feature Engineering Pipeline
df = pd.DataFrame({
    'price_lakh': [25, 45, 80, 120, 300, 750, 1200, 5000],
    'area_sqft':  [600, 850, 1100, 1400, 2000, 3000, 4500, 8000],
    'location':   ['Borivali,Mumbai', 'Andheri,Mumbai', 'Powai,Mumbai',
                   'Bandra,Mumbai',   'Juhu,Mumbai',    'Worli,Mumbai',
                   'Malabar,Mumbai',  'Altamount,Mumbai'],
    'sold': [1, 1, 1, 0, 0, 1, 0, 1]
})

# ── Feature Construction ──────────────────────────────
df['price_per_sqft'] = df['price_lakh'] * 100000 / df['area_sqft']

# ── Feature Splitting ─────────────────────────────────
df[['neighbourhood', 'city']] = df['location'].str.split(',', expand=True)
df['name_length'] = df['neighbourhood'].str.len()

# ── Build Pipeline with FunctionTransformer ───────────
pipeline = Pipeline([
    ('log_transform', FunctionTransformer(np.log1p, inverse_func=np.expm1)),
    ('scaler',        StandardScaler()),
    ('model',         Ridge(alpha=1.0))
])

X = df[['price_lakh', 'area_sqft', 'price_per_sqft', 'name_length']]
y = df['sold']

X_train, X_test, y_train, y_test = train_test_split(X, y, random_state=42)
pipeline.fit(X_train, y_train)

print("Pipeline trained successfully!")
print(f"Score on test: {pipeline.score(X_test, y_test):.3f}")
print(f"\nFeatures used: {list(X.columns)}")
print(f"New feature 'price_per_sqft' range: {X['price_per_sqft'].min():.0f} - {X['price_per_sqft'].max():.0f}")
