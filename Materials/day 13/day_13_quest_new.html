Feature Construction — Naye Features Banao! 🏗️
+100 XP
📖 Kahani Time

Socho tum ek chai ki dukaan chalate ho. Tumhare paas data hai — kitne customers aaye, kitni chai biki, weather kaisa tha. Lekin agar tum ek naya feature banao — jaise "chai per customer" = total_chai / total_customers — toh tumhe zyada insight milegi! Yahi hai Feature Construction — purane data se naye powerful features banana. 🍵

💡 Key Concept

Feature Construction = Creating new features from existing ones using mathematical operations, domain knowledge, or combining columns. Isse model ki prediction power badh jaati hai!

📐 Common Operations

• Ratio: feature_A / feature_B
• Product: feature_A × feature_B
• Polynomial: feature_A²
• Aggregation: mean, sum, count per group

🐍 Python — Feature Construction
import pandas as pd
import numpy as np

# 🍵 Chai Dukaan Dataset
data = {
    'customers': [50, 80, 30, 100, 60],
    'chai_sold': [200, 400, 90, 500, 180],
    'temperature': [15, 10, 25, 8, 20]
}
df = pd.DataFrame(data)

# ✨ Feature Construction — naye features!
df['chai_per_customer'] = df['chai_sold'] / df['customers']
df['temp_squared'] = df['temperature'] ** 2
df['demand_index'] = df['chai_sold'] * (30 - df['temperature'])

print(df.to_string(index=False))

Feature Splitting — Data Ko Todo! ✂️
+100 XP
📖 Kahani Time

Imagine karo tumhare paas ek column hai — "2024-01-15 14:30:00". Yeh ek datetime hai, lekin isme chhupe hain — saal, mahina, din, ghanta! Agar tum ise split karo alag columns mein, toh model ko zyada samajh aayega. Jaise ek Maggi packet ko kholo toh andar masala, noodles sab alag milta hai! 🍜

💡 Key Concept

Feature Splitting = Breaking a single feature into multiple meaningful features. Common examples: datetime → (year, month, day, hour), full name → (first, last), address → (city, state, pin).

🐍 Python — Feature Splitting
import pandas as pd

# 📅 Order data with datetime
orders = pd.DataFrame({
    'order_date': pd.to_datetime([
        '2024-01-15 14:30', '2024-03-22 09:15',
        '2024-07-04 18:45', '2024-12-25 11:00'
    ]),
    'customer_name': ['Rahul Sharma', 'Priya Patel',
                       'Amit Singh', 'Neha Gupta'],
    'amount': [1500, 2300, 800, 5000]
})

# ✂️ Datetime Splitting
orders['year'] = orders['order_date'].dt.year
orders['month'] = orders['order_date'].dt.month
orders['day'] = orders['order_date'].dt.day
orders['hour'] = orders['order_date'].dt.hour
orders['day_name'] = orders['order_date'].dt.day_name()

# ✂️ Name Splitting
orders[['first_name','last_name']] = orders['customer_name'].str.split(' ',expand=True)

print(orders[['customer_name','first_name','last_name',
             'year','month','day','hour','day_name']].to_string(index=False))

FunctionTransformer — Custom Magic! 🪄
+100 XP
📖 Kahani Time

Socho tumhare paas ek magic wand hai 🪄 — tum usse kisi bhi data ko transform kar sakte ho! FunctionTransformer bilkul wahi hai — sklearn ka ek tool jo tumhari custom function ko ek proper transformer mein badal deta hai. Matlab tum apni recipe bana sakte ho aur usse directly sklearn mein use kar sakte ho, jaise ek naya tarka recipe mein! 🍳

💡 Key Concept

FunctionTransformer wraps any Python function into an sklearn-compatible transformer. This means your custom transformations can plug into any sklearn workflow seamlessly!

📐 Syntax

FunctionTransformer(func, inverse_func=None, validate=False)

• func: The transformation function (e.g., np.log1p)
• inverse_func: Reverse transformation (optional)
• validate: Whether to check input arrays

🐍 Python — FunctionTransformer Basics
import numpy as np
from sklearn.preprocessing import FunctionTransformer

# 🪄 Custom function — double the values
def double_it(X):
    return X * 2

# Wrap it as a transformer
doubler = FunctionTransformer(func=double_it)

# Test data
data = np.array([[10], [20], [30], [40]])
result = doubler.transform(data)

print("Original:", data.flatten())
print("Doubled: ", result.flatten())
Original: [10 20 30 40] Doubled: [20 40 60 80]
💡 .transform() vs .fit_transform() — Kya Farak Hai?

FunctionTransformer ke paas 3 key methods hain. Samjho isse — jaise ek chef ki recipe: .fit() = recipe seekhna, .transform() = recipe se khaana banana, .fit_transform() = ek hi step mein dono karna! 👨‍🍳

.transform(data)

🔧 Transform Only

Sirf transformation apply karta hai — pehle se fit hona zaroori hai. Training data pe .fit() call hone ke baad, new/test data pe use karo.

✅ Test data ke liye use karo

.fit_transform(data)

⚡ Fit + Transform Together

Ek hi call mein fit aur transform dono! Internally .fit(data).transform(data) karta hai. Training data ke liye shortcut — time bachata hai.

✅ Training data ke liye use karo

🐍 Python — .transform() vs .fit_transform() Comparison
import numpy as np
from sklearn.preprocessing import FunctionTransformer

# 🪄 Create transformer
doubler = FunctionTransformer(func=lambda x: x * 2)

data = np.array([[10], [20], [30]])

# Method 1: fit() + transform() — 2 steps
doubler.fit(data)               # Step 1: Learn (no-op for FunctionTransformer)
result_1 = doubler.transform(data)  # Step 2: Apply transformation

# Method 2: fit_transform() — 1 step (shortcut!)
result_2 = doubler.fit_transform(data)  # Both in one call

print("fit() + transform():", result_1.flatten())
print("fit_transform():    ", result_2.flatten())
print("Same result?", np.array_equal(result_1, result_2))

# ⚠️ Real-world pattern: Train vs Test
train_data = np.array([[100], [200], [300]])
test_data = np.array([[150], [250]])

# Training: fit_transform (ek hi step)
train_result = doubler.fit_transform(train_data)

# Testing: sirf transform (fit NAHI karna!)
test_result = doubler.transform(test_data)

print("\nTrain transformed:", train_result.flatten())
print("Test transformed: ", test_result.flatten())
fit() + transform(): [20 40 60] fit_transform(): [20 40 60] Same result? True Train transformed: [200 400 600] Test transformed: [300 500]
MethodKya Karta HaiKab Use KaroExample
.fit(X) Parameters seekhta hai data se (FunctionTransformer mein no-op — kuch nahi seekhta) Jab sirf "learning" chahiye, transform baad mein tf.fit(train_data)
.transform(X) Seekhe hue params se data transform karta hai Test/new data pe — fit already ho chuka hai tf.transform(test_data)
.fit_transform(X) fit + transform ek saath — shortcut! Training data pe — pehli baar use karne pe tf.fit_transform(train_data)
.inverse_transform(X) Transform ko ulta karta hai (original value wapas) Predictions ko original scale pe laana tf.inverse_transform(result)
⚠️ Golden Rule — Data Leakage Se Bachao!

Test data pe kabhi .fit_transform() mat use karo! Kyunki yeh test data se "seekhega" — aur yeh cheating hai ML mein! 🚫

✅ Sahi Tarika: fit_transform(train) → transform(test)
❌ Galat Tarika: fit_transform(train) → fit_transform(test)

Note: FunctionTransformer mein fit() kuch nahi seekhta (stateless hai), par StandardScaler, MinMaxScaler jaise transformers mein yeh rule bohot important hai!

4
Log Transform — Skewed Data Ka Doctor! 📈
+100 XP
📖 Kahani Time

Socho ek company mein salary data hai — CEO ka ₹50 lakh, manager ka ₹5 lakh, intern ka ₹20,000. Yeh data right-skewed hai — kuch log bohot zyada kamaa rahe hain! 💰 Agar hum directly ML model lagayein toh CEO ki salary dominate karegi. Solution? Log Transform lagao — sab values ko ek comparable scale pe le aao. Jaise volume knob ko thoda neeche karo taaki sab sunai de! 🔊

💡 Key Concept

Log Transform compresses large values and stretches small values, making right-skewed distributions more normal. Perfect for: salary, house prices, population, revenue — koi bhi data jisme kuch values bohot bade hain!

📐 Formula

• y = log(1 + x) → use np.log1p(x)
• Inverse: x = e^y - 1 → use np.expm1(y)
• Why log1p? Because log(0) = -infinity! Adding 1 makes it safe.

🐍 Python — Log Transform with FunctionTransformer
import numpy as np
import pandas as pd
from sklearn.preprocessing import FunctionTransformer

# 💰 Salary data (right-skewed)
salaries = pd.DataFrame({
    'employee': ['Intern', 'Junior', 'Senior', 'Manager', 'CEO'],
    'salary': [20000, 50000, 120000, 500000, 5000000]
})

# 📈 Apply Log Transform
log_transformer = FunctionTransformer(
    func=np.log1p,
    inverse_func=np.expm1
)

salaries['salary_log'] = log_transformer.transform(
    salaries[['salary']]
)

# 🔄 Verify inverse works
salaries['salary_restored'] = log_transformer.inverse_transform(
    salaries[['salary_log']]
).round(0)

print(salaries.to_string(index=False))
employee salary salary_log salary_restored Intern 20000 9.90 20000.0 Junior 50000 10.82 50000.0 Senior 120000 11.70 120000.0 Manager 500000 13.12 500000.0 CEO 5000000 15.42 5000000.0
⚠️ Yaad Rakho!

np.log(x) mat use karo directly — agar x = 0 toh -infinity aa jayega!
Hamesha np.log1p(x) use karo — yeh internally log(1 + x) karta hai, so zero bhi safe hai. ✅

Reciprocal Transform — Ultaa Kar Do! 🔄
+100 XP
📖 Kahani Time

Socho tum delivery time predict kar rahe ho. Speed 10 km/h wale ko 6 hours lagte hain, par 100 km/h wale ko sirf 36 minutes. Speed badhne se time exponentially kam hota hai — yeh reciprocal relationship hai! 🏍️ Agar hum 1/speed karein toh yeh linear ho jayega — aur ML models ko linear relationships zyada pasand hain! 📏

💡 Key Concept

Reciprocal Transform = 1/x. Yeh inversely proportional relationships ko linear banata hai. Use cases: speed → time, concentration → dilution, frequency → wavelength. Extreme large values ko compress karta hai!

📐 Formula

• y = 1 / x → simple reciprocal
• Safe version: y = 1 / (x + 1) → avoids division by zero
• ⚠️ x = 0 pe crash hoga bina protection ke!

🐍 Python — Reciprocal Transform with FunctionTransformer
import numpy as np
import pandas as pd
from sklearn.preprocessing import FunctionTransformer

# 🏍️ Delivery data
data = pd.DataFrame({
    'vehicle': ['Cycle', 'Scooter', 'Bike', 'Car', 'Bullet Train'],
    'speed_kmph': [10, 40, 60, 100, 300]
})

# 🔄 Reciprocal Transform (safe version with +1)
recip_transformer = FunctionTransformer(
    func=lambda x: 1 / (x + 1)
)

data['speed_reciprocal'] = recip_transformer.transform(
    data[['speed_kmph']]
)

# Also show simple 1/x for non-zero values
data['speed_1_over_x'] = 1 / data['speed_kmph']

print(data.to_string(index=False))
vehicle speed_kmph speed_reciprocal speed_1_over_x Cycle 10 0.090909 0.100000 Scooter 40 0.024390 0.025000 Bike 60 0.016393 0.016667 Car 100 0.009901 0.010000 Bullet Train 300 0.003322 0.003333
⚠️ Yaad Rakho!

Division by zero sabse bada danger hai! Agar x = 0 ho toh 1/x = infinity.
Hamesha 1/(x + 1) ya 1/(x + epsilon) use karo for safety. Epsilon = 1e-6 bhi chal jayega. 🛡️

Square Root Transform — Halka Sa Touch! 🌿
+100 XP
📖 Kahani Time

Instagram pe socho — kisi ko 10 likes milte hain, kisi ko 10,000! Yeh data thoda skewed hai, par utna nahi jitna salary data tha. Iske liye Log Transform bohot heavy ho jayega — jaise cold mein bulldozer lana! 🏗️ Yahan chahiye ek gentle fix — Square Root Transform. Yeh moderate skewness ko fix karta hai bina data ko zyada compress kiye. Jaise halka sa nimbu chai mein — perfect balance! 🍋

💡 Key Concept

Square Root Transform = √x or np.sqrt(x). Yeh Log se milder transform hai — count data ke liye perfect hai (likes, views, clicks, word frequency). Jab data slightly right-skewed ho, yeh best choice hai!

📐 Formula

• y = √x → use np.sqrt(x)
• Inverse: x = y² → use np.square(y)
• ⚠️ x must be ≥ 0 — negative values pe NaN aayega!

🐍 Python — Square Root Transform with FunctionTransformer
import numpy as np
import pandas as pd
from sklearn.preprocessing import FunctionTransformer

# 📱 Social media engagement data
posts = pd.DataFrame({
    'post_type': ['Text', 'Image', 'Reel', 'Story', 'Viral Reel'],
    'likes': [15, 150, 2500, 45, 50000],
    'comments': [3, 25, 400, 8, 8000]
})

# 🌿 Square Root Transform
sqrt_transformer = FunctionTransformer(
    func=np.sqrt,
    inverse_func=np.square
)

posts['likes_sqrt'] = sqrt_transformer.transform(
    posts[['likes']]
)
posts['comments_sqrt'] = sqrt_transformer.transform(
    posts[['comments']]
)

# 🔄 Verify inverse
posts['likes_restored'] = sqrt_transformer.inverse_transform(
    posts[['likes_sqrt']]
).round(0)

print(posts[['post_type','likes','likes_sqrt',
            'comments','comments_sqrt']].to_string(index=False))
post_type likes likes_sqrt comments comments_sqrt Text 15 3.87 3 1.73 Image 150 12.25 25 5.00 Reel 2500 50.00 400 20.00 Story 45 6.71 8 2.83 Viral Reel 50000 223.61 8000 89.44
⚠️ Yaad Rakho!

Negative values pe sqrt kaam nahi karega — NaN return hoga!
Agar negative values hain toh pehle shift karo: np.sqrt(x - x.min()). Count data (likes, views) mein yeh problem nahi aati kyunki counts always ≥ 0 hote hain. 🎯
